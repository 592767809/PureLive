# N02.2 采集镜像与导出记录

- 采用flutter_webrtc1.6.3，保持上游各平台SDK版本。Android补充按track ID区分的MediaProjection停止事件，沿用原事件通道；源码保留LICENSE/NOTICE，打包收集补充通知与WebRTC BSD许可。
- 应用单会话、配对归属、epoch取消、局域网ICE、心跳和断开清理；本机单独允许接收，采集逐次由本机同意。视频仅画面，浏览器本地保存PNG与WebM，保留手动下载入口，无自动上传或内置反馈发送。
- Android16试包实测采集取消无服务残留、旋转1080x2400至2400x1080、系统停止后实际服务和peer释放、重新授权新流、浏览器停止、PNG/VP8视频下载。
- 实际接收可见动态测试画面，断开后返回原设置；生成媒体fixture的原直播间在镜像结束后恢复并刷新一次，原先暂停保持暂停。旧的离屏测试画布曾输出黑帧，挂入控制端页面后验证有效画面，未把黑帧计为成功。
- 四项并发反例均先失败后修复：替换等待旧清理/恢复完成，最新接收开关选择生效，旧本地/远端轨道结束不停止新会话。未连接原反馈硬件；最终同源包的原生互传、桌面及电视验证由Y01.39记录。

状态：源码候选待最终门禁与原生验收，未公开发布。发布与元数据收尾见Y01.39。

补充审查：ReplayKit原实现会在授权完成前返回流，失败只写日志。当前补为等待本机授权结果、拒绝/不可用只失败一次、采样错误/系统停止按轨道结束、原生停止等待确认；CocoaPods与Swift包源码同步。Apple编译和模拟器检查由本次Apple流程执行；iOS真机采集未覆盖，不将模拟器结果当作真机授权验收。
