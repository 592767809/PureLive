# V02.18 任务书

## 范围

关闭开播自动录不删除主播和任务，核验重启自动恢复设置。只修改相关应用逻辑、组件、内核和回归测试。用户可见文字写入 zh/en 翻译，图标与颜色来自 live_ui。

## 要求

关闭时持久保存 autoRecord=false；等待中的任务停止轮询但保留任务和全部选择，正在录制的任务继续本场。只有删除操作移除条目。已有启动恢复设置和每任务选择本来会持久保存，不增加重复开关，不改变全局默认值；说明中明确如何开启重启自动恢复。

## 不能做

不改发布版本和 assets/version.json、assets/releases.json；不操作正式版数据；不清理原 Claude 工作区。未发布前保留 issue，未经复现不声称修复。

## 验收

应用菜单回归要求同一任务仍在且开关为关，旧代码失败。另有两条内核用例验证重启后的任务身份、画质、弹幕与自动开关，以及停用任务不轮询、全局启动恢复关闭时不擅自开录。

先记录能在旧代码失败的缺陷回归，再通过相关测试；推送前全量门禁通过，按 PROCESS 和 ENGINEERING 执行。功能逻辑、构建、设备和发布是独立证据。
