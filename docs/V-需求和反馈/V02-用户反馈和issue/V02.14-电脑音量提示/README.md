# V02.14 电脑音量提示（issue #12）

- 来源：[issue #12](https://github.com/wzgrx/PureLive/issues/12)
- 状态以 [tasks.toml](../../../tasks.toml) 为准；分支 `ai/V02.14`。

## 范围

Windows、Linux、macOS 的鼠标滚轮不再显示视频中间的音量提示。滚轮、方向键、静音和滑块使用同一个播放器音量，底部控制栏显示当前百分比；滑块拖动期间一直显示，其他变化后显示 1.5 秒，固定宽度，不挤动按钮。手机的系统音量与亮度手势保持原样。

## 根因和做法

原滚轮借用了手机的中间提示；滑块的默认数值气泡又不在连续滑块上显示。接手补丁已改为底部固定百分比，但额外缓存了滚轮音量 600 毫秒，会覆盖同一时间内滑块或静音的新值；滑块拖动只刷新 4 秒计时，没有持续持有控制栏。

`PlaybackSession.setVolume` 在等待原生引擎前同步更新 `state.volume`，所以直接读取会话的当前音量即可累加快速滚轮，不需要另设缓存。滑块的开始、结束接入控制栏已有的持有计数；布局切换导致滑块移除时也释放，离开房间后的回调被忽略。

验收步骤见 [verify.md](verify.md)，执行结果见 [record.md](record.md)。
