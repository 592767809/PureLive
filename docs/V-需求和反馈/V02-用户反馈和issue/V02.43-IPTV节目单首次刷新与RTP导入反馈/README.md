# V02.43 IPTV节目单首次刷新与RTP导入反馈

来源：[#48](https://github.com/wzgrx/PureLive/issues/48)，Windows 11 26H2、5.4.13。已回复并标为已计划，保持开放；5.4.14 不包含这两项修复。

原反馈：IPTV 首次进入右侧节目单不显示，点击查看节目单无效，进出全屏后恢复；M3U 与 TXT 的 RTP 源导入失败。

源码和离线证据：m3u_parser.dart 与 txt_parser.dart 的允许协议均无 rtp，iptv_site.dart 使用同一组协议约束。对完全相同的分组格式，仅将 HTTP 改为 RTP：HTTP 的 TXT／M3U 各得到一条，RTP 均为零，M3U 另报一项格式问题。未访问网络，未证明原生组播播放可用。

节目单线索：IptvGuideView 初始化读取元数据，但 didUpdateWidget 主要重挂 reveal 监听；全屏重建视图与原报告的恢复路径相符。这只是候选原因，尚需迟到房间详情的受控回归及原场景验证。

接续：分别建立导入协议与节目单首次刷新回归，覆盖正常 HTTP、切台、详情迟到与重复刷新，确认各端播放器能力后再决定 RTP 支持范围。开发、发布和原机验收应逐项记录；本次只做评估。
