# V02.77 说明

来源：https://github.com/wzgrx/PureLive/issues/138

已查看报告的三张图片，并在受控API28电视模式复现：设置目录第一行按上键跳到左侧“直播”模式项。默认几何导航会选择标题旁更高的菜单项，现有菜单恢复还排除了模式项；默认ensureVisible只揭示第一条可聚焦行，不含其上方不可聚焦标题，滚回后残留189逻辑像素偏移。设置目录第一行现显式保留上键，左键仍返回设置菜单；第一行重新获焦时在当前帧布局后恢复到滚动起点，带回页面和分组标题。只影响目录第一行，不改变其他页面或子页滑块的方向语义。

回归覆盖首次进入后上键停留、左键仍返回设置菜单、右键恢复上次行、下滚后回首行标题恢复。
