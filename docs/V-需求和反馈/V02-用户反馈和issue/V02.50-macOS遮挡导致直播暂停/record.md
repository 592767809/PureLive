# V02.50 macOS遮挡导致直播暂停

来源：https://github.com/wzgrx/PureLive/issues/58。

## 范围与方案

共享手机后台策略把桌面hidden误当作离开应用；按A16.3区分遮挡与原生最小化；原M5现场结果独立记录。

按D-003与本轮用户继续处理issues的授权，沿用现有设置、全屏及返回链；不改平台取流、账号、原生播放内核或手机手势。优先写旧代码失败回归，保留失败与修正记录。

## 允许范围

app/desktop、app/app.dart、routes/app_navigator.dart、features/live_play的后台策略与主画面输入、settings_catalog、live_store设置注册、翻译及对应测试；Apple云端只做本次原生验证，不能将云端结果外推原M5硬件。Windows仅用隔离正式候选；K90仅v4dev保留数据，恢复原界面和旋转。

## 验收

遮挡持续播放、最小化选项开关/恢复/用户手动暂停、移动端后台回归；主画面右键切换往返、弹幕和控件优先、弹窗/页面/首页后退、小窗和多画面不抢事件。定向测试与完整all/14，十包同提交与哈希、各端启动分别记录。真实数据与私有截图不入仓库。

## 5.4.17 候选实现

旧源码两项真实断言失败已保留：macOS遮挡后playing变paused，桌面右键未切换窗口内全屏。桌面生命周期仅更新呈现可见性，自动暂停单独监听DesktopWindow.minimized原生事件；手机规则保留。新增默认关闭的desktopPauseWhenMinimized注册及各语言键，三种桌面可见、两种手机隐藏。鼠标Back使用routerDelegate.popRoute的现有链，首页显式不退出；仅主画面空白处右键切换，飞行弹幕动作优先。

62项定向检查通过，覆盖原有手机/后台和新增遮挡、最小化、手动暂停、切换选项、右键往返/控件/弹幕、弹窗/PopScope/页面/首页返回。首轮测试夹具误用了根路径、平台调试变量在测试体结束后才清理，以及首次表情缓存顺序，均已定位并修正，失败原日志保留，不当成产品缺陷或靠原样重跑豁免。整应用fatal-infos分析通过；新文件所有权索引已生成。

云端Mac新增生成loopback Y4M视频+真实mpv+生产DesktopShell/后台策略的原生检查；Swift独立不透明窗口实际覆盖应用，必须观察真实hidden事件及播放进度继续，再检查最小化开关和恢复。该结果仍不代替M5原机及长期播放。最终全量门禁、构建、原生检查和远端哈希尚待执行，不预先宣称发布成功。


补充审查：关闭按住停弹幕后，飞行弹幕在右键按下与抬起间移动，会导致候选误切全屏；新增长按右键失败回归已保留，改为原始指针按下时固定命中目标、取消时清理，63项定向检查通过。首轮全量门禁为此受控停止，仅停止已核对命令/目录/进程组的本任务作业，日志保留；以下新完整门禁才用于最终源码。


全量门禁发现两项新增设置接线遗漏：默认值审计尚未将desktopPauseWhenMinimized列为v4新键，且开关放在手机后台分组令桌面出现旧契约排除的组标题。已登记新键及默认false，并将桌面开关移至现有播放行为组；原桌面无后台与助眠、手机行和小窗顺序检查原样保留。设置契约与存储默认值定向检查通过；失败全量日志及下游自动阻止构建的回执均保留，未生成任何正式候选包，需新完整门禁。
