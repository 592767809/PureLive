# V02.16 电视关注页从房间卡片向上时回到之前获得焦点的筛选项

来源：[issue #17](https://github.com/wzgrx/PureLive/issues/17)。本轮用户要求全面分析评估并解决新增反馈。工作分支 `ai/V02.15`，基于 5.4.7 发布后的 `fb2bdb61e`。

## 根因与评估

TvFavoritesPane.leaveUp 在没有标签行时固定调用 groupTabs.focusSelected，完全忽略平台行和未选中的焦点项。

## 本次方案

记录离开顶部筛选区时所在的行，TvTabBar 记忆最后焦点；向上恢复该项，条目或整行消失时退到有效选中项。标签行仍按层级经过，向上返回之前的组/平台行。

## 3.x 与参考

以现有 3.x 操作为基线，修复具体缺陷或补足已有功能的状态。参考本机 v3ref（当前上游 `6b9f6c318`）和 pure_live_TV；不复制上游架构，不修改版本和更新通道。

## 验证与边界

真实方向键事件覆盖全部平台、未选中的哔哩哔哩和已开播；旧代码在平台返回断言失败。另有动态移除焦点项回退和向上回调的组件边界回归；真实标签行往返仍待设备验收。

所有“代码修复”均与“真实设备验收”和“已发布”分开记录。除 V02.20 中明确写出的斗鱼登录核验外，本轮未声称 Android TV、掌机、Windows 安装版或 Apple 设备已逐项验收。小范围交互补充沿用现有组件和布局，不重画整个页面；醒目留言会话范围已经用户确认，其他细节按 D-003 选择。
