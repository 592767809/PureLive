# V02.17 链接解析支持省略 https 的直播网址，分享文案和安全边界保持一致

来源：[issue #18](https://github.com/wzgrx/PureLive/issues/18)。本轮用户要求全面分析评估并解决新增反馈。工作分支 `ai/V02.15`，基于 5.4.7 发布后的 `fb2bdb61e`。

## 根因与评估

LinkParser.sharedHttpUrls 的提取表达式只认 scheme:// 和 www.，live.douyin.com/房间号没有进入任何平台解析器。

## 本次方案

对裸域名补 HTTPS，沿用各平台已存在的解析与短链请求预算；签名参数原样保留。不从邮箱、非 HTTP 协议或 javascript: 中截取假链接。手工解析、剪贴板支持识别和电视入口复用同一个提取器。

## 3.x 与参考

以现有 3.x 操作为基线，修复具体缺陷或补足已有功能的状态。参考本机 v3ref（当前上游 `6b9f6c318`）和 pure_live_TV；不复制上游架构，不修改版本和更新通道。

## 验证与边界

新增两项回归旧代码失败；完整 sites_links_test 39 项通过，包含旧短链、取消、中文标点、签名转义和请求预算。

所有“代码修复”均与“真实设备验收”和“已发布”分开记录。除 V02.20 中明确写出的斗鱼登录核验外，本轮未声称 Android TV、掌机、Windows 安装版或 Apple 设备已逐项验收。小范围交互补充沿用现有组件和布局，不重画整个页面；醒目留言会话范围已经用户确认，其他细节按 D-003 选择。
