# V02.32 开发记录

来源：issue #33，华为智慧屏 HEGE-550、Android 10、5.4.10 ARMv7 全新安装；虎牙/斗鱼/哔哩哔哩只有弹幕，没有音视频。

当前尚不能确认原设备根因。弹幕连接与播放媒体是独立路径，不能从弹幕正常推断播放器取流和解码都正常。核对正式 ARMv7 包的 libmpv 依赖，NDK API29 的动态符号可满足；这项静态检查不代表华为厂商系统实测。另发现 native b1 两个 Vulkan 符号不在 API26 桩库中，属于既有最低系统兼容缺口，不能当作 Android10 本问题的已确认根因，单独保留调查线索。

已回复请求失败画面、电视模式和日志，明确不索取 Cookie/验证码。共用 LiveRoomController 以前只记取流阶段和恢复次数，最终播放器错误没有固定分类日志。补充 playback-engine-failure 一次性安全摘要，包含固定类型、白名单原因码、解码模式、纯音频状态和视频尺寸是否已出现。忽略任意异常消息、嵌套异常和任意自定义 code；重复状态不刷屏，重试后再次失败可再记录。手机和电视共用。

边界：本轮是诊断补齐，不能据此宣布智慧屏播放已修复；#33 保持开放，原设备恢复画面和声音后才关闭。#15 同样继续开放。本机 K90 与桌面不能代替原智慧屏、ARMv7 和厂商输出路径验收。

本节为开工范围；最终结果见下方发布交付记录。

## 定向验证

多画面及安全诊断 41 项测试通过，随后新增的窄屏入口和页面截图两项通过。布局回归在旧实现失败；session/音频/恢复、四种尺寸、缩放与全屏验证通过。审查曾发现五项布局改变了原密度阈值，已恢复四项阈值并保持新增项可滑动访问。安全诊断测试验证重复抑制、重试重新记录，以及任意 code/异常原文不会泄露。

原智慧屏故障没有复现，不能记录已修复；完整门禁与原生运行后续写入 Y01.22。
