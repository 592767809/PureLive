# V02.28 接 issue #14：小横屏侧栏的整条拖动与全部入口可达

来源：[issue #14](https://github.com/wzgrx/PureLive/issues/14)。基线 d94f1c934（5.4.9 发布后），分支 ai/V02.26。

## 根因与范围

侧栏在部分高度把目的地固定在下方，只让上方很小的工具区滚动；下方导航项没有滚动祖先。旧测试用 ensureVisible 编程滚动上方工具，没有覆盖用户在下方拖动。

## 方案与既有行为

恢复 3.x 单一侧栏滚动容器，保留全部入口、顺序、选中态和点击行为；手势从整个侧栏发起都能滚动。用实际拖动、点击和缩放测试可达性。

小范围缺陷修正沿用现有界面、入口与组件，不增加新的设置或重画页面。以 3.x 行为和本次实际反馈为基线。

## 验证边界

小横屏、安全区和大字体下逐个访问菜单、搜索、记录、链接、多画面和四个目的地；不把 TV 触屏补充当作本项证据。

代码回归、构建、实际平台、设备和已发布状态分开记录；未经确认不关闭问题。
