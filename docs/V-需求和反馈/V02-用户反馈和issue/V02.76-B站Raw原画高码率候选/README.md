来源：https://github.com/wzgrx/PureLive/issues/137。用户要求新issue解决后一起更新，纳入5.5.0+5132。

参考cat3399/blbl #35、#186及chinasoul/BT #129。新增设置“B站尝试Raw原画”，默认关闭。仅请求且服务端实际交付原画10000、可用档位含250时生成候选；只移除路径尾部已知bluray/prohevc/4k转码标识，保留不透明房间键和签名查询。依次尝试同源和204/204b候选，最多六条，随后完整保留官方线路，重试由既有线路恢复处理。未转码房间、服务端降级、低清晰度、未知路径和非bilivideo主机不改写。原始流编解码未知，不冒用转码线路的codec或虚报分辨率码率。当前公开5050接口实际仅交付250，因此没有把它冒充Raw实网验收。

本轮仅受控AVD与专用桌面目录；原机及原账号未覆盖条件独立保留，不将离线测试或正常匿名探针等同于现场验收。

使用：设置→视频→B站尝试Raw原画。开启后重新进入直播间或刷新取流；仍受平台实际可用原画档限制，无法保证每个CDN提供Raw或固定码率。关闭时完全沿用官方线路。
