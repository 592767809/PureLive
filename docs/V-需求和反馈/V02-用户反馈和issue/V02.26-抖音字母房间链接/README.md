# V02.26 issue #29：抖音自定义字母房间链接被纯数字规则拒绝

来源：[issue #29](https://github.com/wzgrx/PureLive/issues/29)。基线 d94f1c934（5.4.9 发布后），分支 ai/V02.26。

## 根因与范围

DouyinSite.roomIdFromUrl 对 live.douyin.com 只接受数字，与反馈中的自定义字母房间地址不符。

## 方案与既有行为

仅为直播子域接受有限长度的字母、数字、下划线、点和短横线；保留系统路径、路径穿越、错误主机和非直播抖音 URL 的拒绝规则。数字链接、短链和无协议粘贴一起回归。

小范围缺陷修正沿用现有界面、入口与组件，不增加新的设置或重画页面。以 3.x 行为和本次实际反馈为基线。

## 验证边界

反馈中的真实地址做只读检查；解析成功与房间当前是否在播分开记录。

代码回归、构建、实际平台、设备和已发布状态分开记录；未经确认不关闭问题。
