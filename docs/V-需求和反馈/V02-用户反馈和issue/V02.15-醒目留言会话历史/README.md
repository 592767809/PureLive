# V02.15 醒目留言到期后保留本次直播间会话历史，可显示和隐藏

来源：[issue #16](https://github.com/wzgrx/PureLive/issues/16)。本轮用户要求全面分析评估并解决新增反馈。工作分支 `ai/V02.15`，基于 5.4.7 发布后的 `fb2bdb61e`。

## 根因与评估

room_controller.dart 到期时从唯一列表删除，SuperChatList 只能收到活动留言，历史内容已经丢失。

## 本次方案

当前会话内存保留最近 500 条（含活动留言），去重、按时间排序；活动计数仍只计算未到期留言。新增显示/隐藏历史，过期显示“已结束”；同房间重试保留历史，退出会话清空，不写数据库。关闭会员卡设置也从历史中移除对应卡片。

## 3.x 与参考

以现有 3.x 操作为基线，修复具体缺陷或补足已有功能的状态。参考本机 v3ref（当前上游 `6b9f6c318`）和 pure_live_TV；不复制上游架构，不修改版本和更新通道。

## 验证与边界

控制器覆盖去重、到期、重试、数量上限、销毁；组件覆盖默认隐藏、切换、全部过期仍可查看。用户明确选择“当前直播间会话内保留”。

所有“代码修复”均与“真实设备验收”和“已发布”分开记录。除 V02.20 中明确写出的斗鱼登录核验外，本轮未声称 Android TV、掌机、Windows 安装版或 Apple 设备已逐项验收。小范围交互补充沿用现有组件和布局，不重画整个页面；醒目留言会话范围已经用户确认，其他细节按 D-003 选择。
