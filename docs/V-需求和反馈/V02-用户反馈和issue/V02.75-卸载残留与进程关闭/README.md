# V02.75 卸载残留与进程关闭

来源：https://github.com/wzgrx/PureLive/issues/136。用户要求新issue解决后一起更新，纳入5.5.0+5132。

CloseApplications只覆盖安装过程，原卸载路径没有显式等待运行实例退出。新增预引擎--shutdown-for-uninstall命令，用规范化的完整可执行文件路径匹配本安装实例，通过专用窗口消息进入Dart保存窗口和停止录制的退出路径，不走隐藏到托盘。所有匹配进程退出才返回独立确认码42；超时或身份不明返回失败。Inno在usUninstall、任何文件删除前执行并等待，失败抛错中止。独立确认码也防止降级后的旧程序忽略参数却误报成功。保留AppData和UserData；不按进程名全局强杀。

本轮仅受控AVD与专用桌面目录；原机及原账号未覆盖条件独立保留，不将离线测试或正常匿名探针等同于现场验收。
