# V02.38 iPhone 全屏亮度和音量手势无效反馈

来源：[issue #41](https://github.com/wzgrx/PureLive/issues/41)，iPhone 15 Pro Max、5.4.12，报告全屏左右拖动均无效。系统版本和原生日志尚缺。

现有手势会异步读取系统初值；读取期间所有移动直接返回，短手势可能在读取结束前松手，导致没有任何设置调用。旧读取还可能覆盖后一个手势的状态。先用受控延迟回读保存修改前失败，再修正这条可证明的时序缺口；不能把它直接当成原反馈设备的唯一根因。

保留 3.x 左亮度、右媒体音量、全高 1.2 倍增益及每帧合并。正常松手保留已经发生的位移；取消、新手势、锁定或销毁使旧回读失效。不改变界面、原生 API 或进房间默认值。


反馈者在 [后续留言](https://github.com/wzgrx/PureLive/issues/41#issuecomment-6383992297) 补充系统为 iOS 18.7.8；是否出现 HUD 和原生亮度／音量变化仍待复测。
