# V02.38 记录

2026-10-24：登记并分析异步回读丢弃移动的路径，准备修改前回归；尚未改产品代码。


修改前：六项延迟/旧回读回归失败，另六项生命周期检查通过；修正测试夹具平台变量清理后保存干净 RED。旧实现等待回读时直接丢掉全部位移。

实现：每个手势独立代次，回读期间用常量空间组合逐步 clamp 的位移变换；正常松手仍应用已发生的位移。新手势、锁定、销毁或 pointer cancel 使旧回读失效；接受后的拖动遇 PointerCancelEvent 会触发 onEnd，因此补上透明 Listener 的取消路径。原有每帧合并、系统边缘和恢复面板不变。

结果：18 项受控回读回归与 26 项原有房间弹层/音量/边缘/每帧合并检查全部通过。测试涵盖短拖后回读、活动拖动、旧回读、两端饱和后反向、取消、锁定、解锁、销毁。原 iPhone 系统版本和实际原生效果仍待反馈，不关闭 #41。
