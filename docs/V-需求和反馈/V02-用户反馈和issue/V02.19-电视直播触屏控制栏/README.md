# V02.19 补充 issue 14：TV 直播画面可用触屏呼出和收起控制栏

来源：[issue #14](https://github.com/wzgrx/PureLive/issues/14)。本轮用户要求全面分析评估并解决新增反馈。工作分支 `ai/V02.15`，基于 5.4.7 发布后的 `fb2bdb61e`。

## 根因与评估

TvLivePlayPage 只有遥控器确认键调用 showControls；画面没有触屏点击入口，平板和掌机进入 TV 模式后无法呼出控制栏。

## 本次方案

只在画面层增加点击显示/隐藏；按钮和弹出面板保持自己的点击行为，失败状态不误触控制栏。原遥控器方向键、返回和控制栏超时逻辑沿用。

## 3.x 与参考

以现有 3.x 操作为基线，修复具体缺陷或补足已有功能的状态。参考本机 v3ref（当前上游 `6b9f6c318`）和 pure_live_TV；不复制上游架构，不修改版本和更新通道。

## 验证与边界

旧代码中点击画面后找不到控制栏；修复后触屏显示/收起、方向键换台、返回和右侧设置面板回归通过。原始小屏侧栏问题尚未在反馈设备复现，不能把这项触屏补充当成侧栏已修复。

所有“代码修复”均与“真实设备验收”和“已发布”分开记录。除 V02.20 中明确写出的斗鱼登录核验外，本轮未声称 Android TV、掌机、Windows 安装版或 Apple 设备已逐项验收。小范围交互补充沿用现有组件和布局，不重画整个页面；醒目留言会话范围已经用户确认，其他细节按 D-003 选择。
