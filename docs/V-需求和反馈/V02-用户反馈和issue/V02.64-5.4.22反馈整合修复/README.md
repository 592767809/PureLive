# 5.4.22反馈整合修复

桌面切换面板分类使用固定40高的横向ListView，1280宽窗口中第四项右边界达到1354，超出可点击区域；普通鼠标滚轮不能发现横向隐藏项。桌面改用自动换行，触摸端保留横向浏览并适配文字高度。醒目留言已有showFullscreenSuperChat持久化设置，但直播间共享设置遗漏入口；补齐入口，默认值和接收/历史逻辑不变。

#104自动同步行InkWell和内部Switch都可聚焦，改为电视SettingsRow统一绘制白框，内部Switch仅展示，确定键切换一次，左右键导航不切换值。#103首选平台使用同一PlatformLogo，AppOptionRequest和电视转换层必须完整保留leading。

PR#107原提交b3c071929cf0d7a4a75213e32700986a0817d0ca纳入独立分支，保留贡献历史。新增只读播放信息；审查修正零/缺失下载速率仍显示旧平均值的问题。贡献者云CI不替代本次本地门禁及最终包验证。
