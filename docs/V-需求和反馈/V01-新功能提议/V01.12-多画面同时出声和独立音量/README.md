# 多画面同时出声和独立音量

来源：[#87](https://github.com/wzgrx/PureLive/issues/87)。Windows用户希望2×2或1×4同时听到四间房并独立调音量。

当前每格音量已保存，但MultiviewController._audibleVolume只允许_audio对应格发声。实现需增加默认关闭的多路声音模式，让网格各格使用自身音量，同时定义全部静音、音源标记、聚焦布局、房间替换和自动换台行为；不能只移除音源判断造成旧用户默认混音。

本需求在5.4.19最终源码冻结后收到，未包含在本次包中。保留开放；下一阶段先补控制器音量分配、UI可达和真实Windows多路音频验证。

## 2026-10-28实施设计

顶栏增加“多路声音”开关，沉浸/全屏同样可切换；默认关，开启后各格按保存音量发声，点击格只改变选中格/弹幕，不静音其他格。1+3也遵循所选声音模式。全部静音优先；切回单音源后仅当前选中格发声。关闭一格、替换房间、自动换台和布局变化沿用已有会话，不重建其余播放器。每格音量0仍静音；声音模式作为独立偏好保存，切换开关不覆盖上次布局和待恢复房间。用户已授权自主决定，采用现有按钮和图标体系，窄屏布局仍可滚动。
