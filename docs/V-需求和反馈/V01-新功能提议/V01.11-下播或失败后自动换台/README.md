# V01.11 下播或最终失败后自动切换在线关注房间

来源：[issue #68](https://github.com/wzgrx/PureLive/issues/68)，[评估回复](https://github.com/wzgrx/PureLive/issues/68#issuecomment-6423599444)。原功能没有自动选下一个房间；当前已有播放恢复及多画面会话复用，不应以新的自动跳转覆盖瞬时缓冲和线路重试。

建议默认关闭，首阶段仅在确认下播或现有恢复耗尽后，从在线关注中选择下一房间；每窗口独立，跳过当前房间及其他窗口已播放房间，单轮不重复，候选耗尽停止。停止/切房/关闭窗口时取消旧候选查询，防止过期结果替换用户新选择；多画面保留各窗口布局和静音策略。热门/分类作为后续候选来源另行评估。

影响范围：G播放恢复终态、J设置持久化、A播放及多画面开关、关注在线状态查询。需先验证终态定义与取消协议，再实现设置和每窗口调度，最后验证单房间、多画面、断网、全离线和用户手动切房。规模大，当前仅登记和评估，没有实现，不属于5.4.18已修复项。
