# O02.1 画中画复验：真机验证

- 设备：本机模拟器 k90a16（Android 16，x86_64，和 K90 同尺寸）。2026-10-15 用户定：K90 上有别的程序在用，真机实测改到模拟器上做。
- 构建：`com.mystyle.purelive.v4dev`（profile，x86_64），5.1.0 测试包，提交 `08826a5f2`。
- 日期：2026-10-15；验证人：Claude（用户授权）。直播间：哔哩哔哩“哔哩哔哩王者荣耀赛事”（横屏画面）。

| 步骤 | 期望 | 结果 |
|---|---|---|
| 1. 点上栏小窗按钮 | 进系统画中画，只有画面和小窗弹幕 | 通过：头一两帧是黑的（系统过渡），随后画面和弹幕正常，没有应用自己的按钮。 |
| 2. 回到应用 | 控制条显示，4 秒后隐藏；点画面出来；全屏进横屏；返回退出全屏 | 通过：回来控制条在，不碰几秒后自己隐藏；点画面出来；点全屏进横屏全屏（系统第一次会提示“目前处于全屏模式”，是 Android 自己的）；返回键退出全屏回竖屏直播间。 |
| 3. 从最近任务回来 | 同第 2 步 | 通过（用 `am start` 把任务拉回前台，和点最近任务卡片一样）。 |
| 4. 暂停后进画中画，再回来 | 控制条一直显示，中间 ▶ 点了继续播放 | 通过：回来 8 秒后控制条仍在、中间 ▶；点了继续播放，控制条随后自己隐藏。 |
| 5. 横屏全屏加锁后进画中画再回来 | 回到横屏全屏、锁已解除 | 没做：模拟器上不便同时做双击和锁屏手势；由已有自动测试覆盖（`live_play_page_test`）。 |
| 6. 打开“离开应用时自动画中画”，播放中按 Home | 自动进画中画 | 通过。 |
| 7. 画中画里点系统的按钮 | 在播是“暂停”，点了暂停、按钮变“播放”；再点继续 | 通过：系统按钮在播时是暂停，点了画面停住、按钮变 ▶（系统日志 `PIP remote actions=[播放|静音]`）。注意系统按钮会自己隐藏，要先点一下窗口让它出来再点。 |
| 8. 抖音竖屏主播进画中画 | 窗口按真实比例是竖的 | 没做：模拟器上抖音取流常要登录；留给真机。 |
| 9. `appops` 关掉画中画后点小窗按钮 | 不进画中画；提示条带“去设置”；“去设置”打开系统画中画设置；恢复后正常 | 通过：提示“无法打开画中画：系统设置里关掉了“纯粹直播”的画中画”，带“去设置”；“去设置”打开系统设置（`com.android.settings/.spa.SpaActivity`）；恢复权限后小窗按钮正常进画中画。 |

## 结论

- 通过：S02.1 修的“从画中画回来控制条卡住”在模拟器上没有复现，回来后控制条照常显示、隐藏、响应；这一项可以关。
- 没做的：第 5 步（自动测试覆盖）、第 8 步（抖音竖屏，留给真机）。
