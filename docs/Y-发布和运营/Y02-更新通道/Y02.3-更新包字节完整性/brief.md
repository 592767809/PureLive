# Y02.3 任务书

## 范围

修复共享下载器的字节完整性、部分文件身份、HTTP 完成判定和替换保护；在更新模型/界面增加精确大小及 SHA-256、保留原始下载源；增加离线发布清单工具。保留 Y02.2 的快照与防降级规则、3.x 发布格式、字体旧调用 API 和现有文件名净化。不修改正式 feed、版本号、签名及发布资产。

## 验收

1. 旧 API 回归证明 416 非空分片、超长/空响应、错误 206 和跨镜像混合字节问题，源上限回归证明原始地址被排除。
2. 新 API 回归覆盖精确大小/摘要、全文件流式校验、部分文件与身份更换、完整分片复用、重试上限、200/206/416、头大小写、损坏内容和原始地址兜底。
3. 所有取消/磁盘失败不提前声明成功；旧目标按明确提交边界保留或可恢复。失败注入不依赖文件权限或真实安装器。
4. 旧历史可读且可明确在浏览器下载；缺失/损坏元数据没有未校验的应用内安装按钮。15 个语言表新增文案均为中文。
5. 发布工具从最终产物和 SHA256SUMS 生成/验证新增字段，拒绝重复、混合构建、错误标签/名称/摘要；覆盖现有十种跨平台安装包和旧字段兼容。
6. 执行下载器、更新、字体/服务、发布工具回归，静态分析、仓库检查及全量门禁；真机和发布验证单列未验证边界。
