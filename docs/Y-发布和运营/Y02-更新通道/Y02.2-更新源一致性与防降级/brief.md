# Y02.2 任务书

## 背景与目标

#70 的 Sony Android 9、5.4.18 用户看到 5.4.18 无安装包与 5.4.17 有下载入口交替出现。解决元数据响应竞争和更新候选保护，不推断已经发生降级安装。

## 范围

可改 `apps/pure_live/lib/features/version/` 的检查/下载入口逻辑、对应测试、15 个翻译 JSON、本任务文档与登记表。不得改版本号、两个发布 JSON、共享下载器、字体、签名或 TV 外壳。

## 验收

- 旧缓存/坏响应不能遮蔽期限内有效新响应；选择有上限、请求会取消。
- 所显示的版本、构建与提供的包一致；同版本错构建、无身份文件不能升级。
- 新版、当前、旧/不可用、上次结果明确区分；当前/旧构建无升级安装入口。
- 刷新、销毁和并发迟到不污染角标/快照；有效上次快照离线可看且不宣称新鲜。
- 主动历史下载保留确认和独立意图；正常十包/平台覆盖及原跳过行为不丢。
- 新可见文字为中文，15 个语言表新增键集一致。

## 验证

先用仅依赖旧 API 的 race 回归在基线运行，确认行为失败而非编译失败；再跑五个更新测试文件、分析、文档/结构检查及完整门禁。原设备验证见 verify.md。
