# 5.4.23发布

2026-10-30：Android API28生成媒体原生恢复与实际画面通过；准备完整门禁和同源构建。


## 发布前暂停边界复查

首轮候选987c03a虽通过all/14与Android/Windows生成媒体恢复验证，进一步发现“旧内核释放期间用户暂停”仍会启动替代播放器。新增反证断言失败（预计1个内核，实际2个）。因此首轮草稿保持未公开，安装包及原生证据完整保留，最终版本重新构建。

_openSource在自动恢复入口与异步初始化后重新核对播放意图；音量命令迟到时，已暂停的源不再提交为活动输入；原生open迟到完成时也执行真正的pause，而不是仅显示暂停文字。三项新增回归覆盖释放期暂停、音量排队期暂停及open未完成时暂停，用户resume后继续播放。

最终r5所属116项测试通过；Android API28探针重复了404、短连接停顿、长停顿重建、手动换线，并在恢复后暂停13秒，确认原生pause=yes、时间不推进、内核数量不变；主动resume后实际画面继续推进。r5运行时代码哈希与冻结提交核对，新增代码重新all/14及同源十包，不复用旧候选安装包。
