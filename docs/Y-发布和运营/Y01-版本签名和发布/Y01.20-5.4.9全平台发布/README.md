# Y01.20 5.4.9 全平台发布

用户明确要求解决问题、发布更新、合并 PR、关闭 issues。本次发布 5.4.9+5113，对应 PR #27；#21–#25 已有候选实现，发布后逐项回复并关闭，未覆盖的反馈者真机验收仍记待真机。#14、#15、#26 不冒充解决并保留跟踪。

版本和发布说明独立提交；每次推送前完整门禁必须通过。同一提交构建十个包：Android 三 ABI、Windows 便携与安装、Linux 压缩包、macOS DMG/ZIP、iOS unsigned/TrollStore。Android、Linux、Windows 本地串行构建，Apple 按 D-041 云构建。核对包名、版本、签名、通知图标、16 KB 对齐；K90 只操作授权的 v4dev 并保留数据；Windows 测试在工作目录，不操作正式安装。各端启动必须看图，不能仅凭进程存在。

先建未公开草稿，核对十包与 SHA256SUMS 的远端哈希，核对源码、门禁和 Apple 构建提交，之后按本次用户授权合并并公开。新旧更新文件保持历史和旧客户端兼容，只同步同样两个 JSON；旧库既往单次门禁例外不能自动沿用。发布、源码回归、构建、启动和真实设备交互分别记录，不记入真实账号、Cookie、设备地址或签名密钥。
