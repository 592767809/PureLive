# Y01.23 5.4.12 全平台发布（构建号 5116）：电视关注页返回层级

来源：[issue #35](https://github.com/wzgrx/PureLive/issues/35)。5.4.11 已完成发布、两仓库更新和审计；本项在独立分支处理，计划发布 5.4.12+5116。

## 方案

关注页的房间卡片和离线行获得焦点时，返回先恢复最近进入列表的状态／平台筛选行，保留选择、列表和滚动位置；再次返回交给首页回到左侧菜单，再次返回保留原退出确认。标签筛选行也先返回上方状态／平台行。只有一个平台时回到状态筛选。

使用现有 TvHomeHost.setBackHandler 与 TvTabBar 的焦点记忆；通过列表内容自身的焦点范围判断是否消费返回，防止左侧菜单的返回被关注页夺走。隐藏页面、弹窗、房间页面和独立页面继续使用既有返回链。按 D-003 采用此最小实现；没有新增用户文案、设置或数据格式。

## 验收

| 用例 | 预期 |
|---|---|
| c1 卡片返回 | 卡片 → 最近使用的状态／平台筛选 → 菜单 → 退出确认 |
| c2 未选中的平台焦点 | 返回恢复刚聚焦的平台，已选筛选保持不变 |
| c3 离线房间行 | 与卡片相同的两级返回 |
| c4 空列表与单平台 | 状态页操作返回状态筛选，再返回菜单 |
| c5 标签筛选 | 列表和标签行返回上方状态／平台筛选，不修改标签选择 |
| c6 通道与生命周期 | Android 原生返回和页面返回一致；菜单、对话框、其他页及销毁后的处理正常 |

本节为方案；代码、回归、完整门禁、构建、合成画面、K90 v4dev 和发布结果分别记录，不提前声称原盒子或所有遥控器验收通过。
