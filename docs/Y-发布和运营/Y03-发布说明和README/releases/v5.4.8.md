# 纯粹直播 5.4.8（Android、电视、Windows、Linux、macOS、iOS、iPadOS）

5.4.8 增加当前直播间的醒目留言历史，修复电视关注页焦点返回、无协议头网址解析和关闭自动录制时条目丢失，并补上 TV 模式触屏呼出播放控制栏。

下载：[Releases](https://github.com/wzgrx/PureLive/releases/latest)，选对应平台的安装包（见文末“下载哪个”）。

## 主要变化

- **醒目留言历史**（[#16](https://github.com/wzgrx/PureLive/issues/16)）：增加“显示历史 / 隐藏历史”，过期卡片标“已结束”。默认隐藏历史，本次直播间会话保留最近 500 条（含活动留言）；同房间重试保留，退出会话清空，不写磁盘。
- **电视关注页焦点**（[#17](https://github.com/wzgrx/PureLive/issues/17)）：从房间卡片向上返回时，回到之前离开的组或平台按钮，包含尚未选中的焦点项；原项被移除时回退到有效项，有标签行时按层级返回。
- **直接输入直播网址**（[#18](https://github.com/wzgrx/PureLive/issues/18)）：`live.douyin.com/房间号` 等省略 `https://` 的网址会自动补全，再走平台解析；分享短链沿用原有请求预算。
- **关闭自动录制保留主播**（[#19](https://github.com/wzgrx/PureLive/issues/19)）：停用开播自动录制后保留任务、清晰度和弹幕选项，停止等待轮询；正在录制的本场继续。逐主播设置原本就会保存，重启后自动恢复还需在录制设置开启“应用启动时恢复待录任务”。删除仍使用单独的删除操作。
- **TV 模式支持触屏控制**（[#14](https://github.com/wzgrx/PureLive/issues/14) 的补充建议）：点击播放画面可显示或隐藏控制栏，平板、掌机可直接触屏操作；遥控器和手柄操作沿用现有逻辑。
- 新增文案同步到全部 15 个语言包。

## 从旧版本升级

- 直接覆盖安装，保留原有数据；不要先卸载。
- 本次没有修改数据库、录制全局默认值或新增重复的自动恢复开关。

## 已知问题与验证范围

- 部分账号斗鱼登录后无法播放（[#15](https://github.com/wzgrx/PureLive/issues/15)）仍在跟踪；授权红米账号在 5.4.7 的官方短信登录、冷启动及两个直播间均正常，不能据此认定其他账号正常。本版没有未经证实的鉴权补丁。
- 小横屏设备原侧栏无法滑出更多项目（[#14](https://github.com/wzgrx/PureLive/issues/14)）仍待反馈设备日志和录屏；本次仅补齐 TV 模式的触屏入口，不代表原侧栏问题已修复。
- 源码回归覆盖 SC 历史、焦点和删除项回退、实际抖音链接解析、短链与录制持久化。发布构建、启动截图和 K90 冒烟的确切结果记录在 Y01.19；Apple 真机、实体电视遥控器及各端完整交互仍未逐项验收。
- iPhone、iPad 最低 iOS、iPadOS 15，Mac 最低 macOS 12。苹果平台录制暂不可用，iPad 系统画中画和台前调度仍待支持；其余已知问题沿用 5.4.7。外语译文尚未经过母语者校对，Windows 安装版没有覆盖安装验收。

问题和建议请到 [Issues](https://github.com/wzgrx/PureLive/issues) 反馈。
