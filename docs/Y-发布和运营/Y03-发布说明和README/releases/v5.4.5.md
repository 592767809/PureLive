# 纯粹直播 5.4.5（Android、电视、Windows、Linux、macOS、iOS、iPadOS）

5.4.5 重做了首页玻璃底栏的手感：静止时是一块灰色药丸，按下、滑动时才变成玻璃透镜，所有动作都换成弹簧动画；平板也可以用底栏了。

下载：[Releases](https://github.com/wzgrx/PureLive/releases/latest)，选对应平台的安装包（见文末“下载哪个”）。

## 主要变化

### 玻璃底栏（手机、平板）

- **静止时更干净**：选中项是一块灰色药丸；**按下、滑动时才变成玻璃透镜**，透镜会放大、折射底下的内容，边缘有彩虹色散，到位后变回药丸。
- **弹簧手感**：按下时透镜鼓起来、轻轻回弹；滑得越快，透镜拉得越长，停下时回弹一下；按住时整条底栏微微放大，左右拖动时跟着偏一点，松手弹回。
- **透镜里是选中色**：透镜经过的图标变成选中的颜色，经过一半就一半变色。
- 按住时手指处有一团柔光；透镜有投影，在白色页面上也看得清。
- 系统里关掉动画时，底栏直接切换，不做这些动画。

### 平板

- 新设置：设置 → 外观 → 主题 →“**平板也用底栏**”（默认关）。打开后平板、展开的折叠屏首页也用底栏，玻璃胶囊居中、最宽 560；侧栏里的搜索、观看记录、链接解析、多画面从左上角菜单和右上角搜索进入。（[#4](https://github.com/wzgrx/PureLive/issues/4)）

### 反馈

- 仓库的问题反馈改成表单：问题反馈、直播平台失效、功能需求、翻译和文字，版本、设备、复现步骤必填；流程、状态和时限见 [CONTRIBUTING.md](https://github.com/wzgrx/PureLive/blob/master/CONTRIBUTING.md)。
- 旧仓库 wzgrx/pure_live 的首页和发布页都写明了已搬到这里（[#3](https://github.com/wzgrx/PureLive/issues/3)）。

## 从旧版本升级

- **直接覆盖安装，不要先卸载**：卸载会把数据一起删掉。
- 这一版没有改数据库；新设置“平板也用底栏”默认关，原来的用法不变。

## 已知问题

- macOS、iOS、iPadOS 版仍然只在 GitHub 的构建机和 iPhone 模拟器上打开过，没有在真机上用过：分享、锁屏正在播放、后台播放、快捷键列表要等有人在真机上用过才算确认；录制在苹果平台上暂时不可用；iPad 的系统画中画和台前调度还没做。
- 小窗浮在其他应用上面时，小米 HyperOS 等系统在内存紧张时可能结束应用，小窗随之消失；可以在系统设置里给纯粹直播“无限制”的后台权限。
- 5.4.1 的其他已知问题照旧：外语译文由 AI 翻译，没有母语者校对；官方登录没有用真实账号逐个登录过；Kick 只在 Android 上能用；HyperOS 划掉应用后可能结束录制和后台播放；Android 15 起录制一天累计最多 6 小时；Windows 安装版没有在测试电脑上安装。

问题和建议请到 [Issues](https://github.com/wzgrx/PureLive/issues) 反馈。

## 下载哪个

| 文件 | 适用 |
|---|---|
| `PureLive-5.4.5-5109-debug-signed-android-arm64-v8a-release.apk` | 绝大多数手机、平板和电视盒子（64 位 ARM），不确定就选这个 |
| `PureLive-5.4.5-5109-debug-signed-android-armeabi-v7a-release.apk` | 老的 32 位 ARM 手机、电视 |
| `PureLive-5.4.5-5109-debug-signed-android-x86_64-release.apk` | x86_64 模拟器和设备 |
| `PureLive-5.4.5-5109-windows-x64-setup.exe` | Windows 安装版 |
| `PureLive-5.4.5-5109-windows-x64-portable.zip` | Windows 便携版（解压即用，数据在程序旁边的 UserData） |
| `PureLive-5.4.5-5109-linux-x64.tar.gz` | Linux x86_64 |
| `PureLive-5.4.5-5109-macos-universal.dmg` | macOS（Intel 和 Apple 芯片） |
| `PureLive-5.4.5-5109-macos-universal.zip` | macOS，同上，压缩包 |
| `PureLive-5.4.5-5109-ios-unsigned.ipa` | iPhone、iPad，用 AltStore 或 SideStore 安装 |
| `PureLive-5.4.5-5109-ios-trollstore.ipa` | 装了 TrollStore 的 iPhone、iPad |

Android 包的签名和 3.2.11、4.x、5.x 相同，可以直接覆盖安装。最低 Android 8.0。macOS 第一次打开如果提示“无法验证开发者”，到 系统设置 → 隐私与安全性 → 点“仍要打开”。
