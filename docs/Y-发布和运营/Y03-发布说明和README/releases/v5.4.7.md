# 纯粹直播 5.4.7（Android、电视、Windows、Linux、macOS、iOS、iPadOS）

5.4.7 修复电视对话框的遥控器操作和玻璃底栏拖动卡顿，调整底栏位置、尺寸与玻璃质感，加入已关注标记，并优化电脑调音量时的显示。

下载：[Releases](https://github.com/wzgrx/PureLive/releases/latest)，选对应平台的安装包（见文末“下载哪个”）。

## 主要变化

### 电视遥控器（[#8](https://github.com/wzgrx/PureLive/issues/8)）

- **对话框里的按钮能选中了**：电视上打开的对话框（设备同步的“发送配置”、更新提示、退出确认等）以前方向键选不到里面的选项和按钮，只能按返回关掉。现在方向键逐个选中，确认键勾选或按下；键盘的回车照旧。

### 首页底栏（[#9](https://github.com/wzgrx/PureLive/issues/9)）

- **玻璃底栏往下收**：以前胶囊下面是“整个手势条区域再加 12”，在 iPhone 上空出一大块。现在胶囊离屏幕底边 20，贴着 iPhone 的手势条，和 iOS 26 自带底栏的位置差不多；Android 有手势横条的手机也一样收紧，在横条上方留一点空隙。三键导航还是在按钮上方，没有底部横条的手机不变。
- **新设置“紧凑底栏”**（设置 → 外观，默认关）：打开后普通底栏从 80 变成 64，玻璃底栏从 68 变成 56，小屏手机能多看到一点内容。

### 玻璃底栏的质感与拖动（[#11](https://github.com/wzgrx/PureLive/issues/11)）

- **拖动更跟手**：连续移动时接着当前弹簧调整目标，避免每次重新开始而停顿。
- **玻璃质感**：调整背景漫射、边缘折射和高光，去掉底栏投影；深色玻璃更亮，按住时透镜内的图标一起放大。
- **新设置“玻璃质感”**（设置 → 外观）：液体玻璃开启后可调，往左更通透，往右更磨砂，默认在中间。

### 电脑调音量（[#12](https://github.com/wzgrx/PureLive/issues/12)）

- **滚轮不再遮挡画面**：Windows、Linux、macOS 上用滚轮调音量时，不再弹出画面中间的音量条，改由底部控制栏显示。
- **拖动时看得到百分比**：音量条右侧显示百分比，按住滑块期间保持可见；滚轮、方向键或静音键改变音量后，百分比短暂显示再淡出。滑块和滚轮混用时从当前音量继续调整。
- 手机调系统音量的手势保持原样。

### 已关注标记（[#10](https://github.com/wzgrx/PureLive/issues/10)）

- **浏览时能看出关注过哪些直播间**：热门、分区、搜索和历史里，已经关注的直播间封面左上角（平台标签后面）有一个小红心，和电视版一样；读屏会念“已关注”。关注页本身不显示。卡片样式选“简洁”时，红心在右边的数字前面。

## 从旧版本升级

- **直接覆盖安装，不要先卸载**：卸载会把数据一起删掉。
- 这一版没有改数据库；“紧凑底栏”和“液体玻璃”默认关，已有的外观设置保留。启用液体玻璃时会看到本次的质感调整。

## 已知问题

- iPhone、iPad 最低 iOS、iPadOS 15，Mac 最低 macOS 12。iOS 14 及更早的设备用 TrollStore 也能装上，但打不开：开发框架 Flutter 最低要 iOS 15，没办法支持（[#7](https://github.com/wzgrx/PureLive/issues/7)）。
- macOS、iOS、iPadOS 版仍然只在 GitHub 的构建机和 iPhone 模拟器上打开过，没有在真机上用过：分享、锁屏正在播放、后台播放、快捷键列表要等有人在真机上用过才算确认；录制在苹果平台上暂时不可用；iPad 的系统画中画和台前调度还没做。
- 小窗浮在其他应用上面时，小米 HyperOS 等系统在内存紧张时可能结束应用，小窗随之消失；可以在系统设置里给纯粹直播“无限制”的后台权限。
- 5.4.1 的其他已知问题照旧：外语译文由 AI 翻译，没有母语者校对；官方登录没有用真实账号逐个登录过；Kick 只在 Android 上能用；HyperOS 划掉应用后可能结束录制和后台播放；Android 15 起录制一天累计最多 6 小时；Windows 安装版没有在测试电脑上安装。

问题和建议请到 [Issues](https://github.com/wzgrx/PureLive/issues) 反馈。
