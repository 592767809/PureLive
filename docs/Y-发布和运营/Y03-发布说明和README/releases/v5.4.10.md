# 纯粹直播 5.4.10（Android、电视、Windows、Linux、macOS、iOS、iPadOS）

5.4.10 修复小屏横屏侧栏、电视设置焦点边框和抖音自定义房间链接，启用 Windows KICK，并补齐斗鱼聊天等级、粉丝牌和通知。

下载：[Releases](https://github.com/wzgrx/PureLive/releases/latest)，按文末“下载哪个”选择安装包。直接覆盖安装，保留原有数据，不必卸载。

## 主要变化

- **小屏横屏侧栏**（[#14](https://github.com/wzgrx/PureLive/issues/14)）：整条左侧栏可以上下滑动，从下方导航项上拖动也能找到菜单和工具，入口顺序和选中行为保持一致。
- **抖音房间链接**（[#29](https://github.com/wzgrx/PureLive/issues/29)）：支持 `live.douyin.com/jianailiang2019` 这类自定义字母房间地址，有无协议及短链落地均可解析。
- **电视设置焦点框**（[#30](https://github.com/wzgrx/PureLive/issues/30)）：二级设置行保持原尺寸，圆角和点击效果一致；首选平台等整行选项的边框完整显示。
- **Windows KICK**（[#26](https://github.com/wzgrx/PureLive/issues/26)）：开放已有 KICK 平台，沿用应用代理设置，支持目录、搜索、播放与聊天。
- **斗鱼聊天信息**（[PR #28](https://github.com/wzgrx/PureLive/pull/28)）：弹幕列表补齐用户等级和粉丝牌，按等级配色，并保证不同主题下的可读性；关闭用户名时一起隐藏。补齐贵宾数量和禁言通知，忽略明确属于其他房间的通知。
- **斗鱼身份缓存与诊断**（[#15](https://github.com/wzgrx/PureLive/issues/15)）：凭据变化后刷新对应的签名描述符，隔离账号切换期间的过时请求；失败日志增加固定原因码，方便区分签名描述符与播放响应错误。

## 已知问题与验证范围

- 斗鱼“登录后所有房间无法播放”的原反馈仍待受影响账号确认。缓存修正与匿名巡检通过不能代表该账号问题已经完全解决，#15 继续开放。如仍失败，请提供首次失败时间及 `playback-failure` 的 `phase/kind/code` 行，不要发送登录凭据或完整接口响应。
- K90 测试包已验证侧栏拖动、电视设置焦点和平台弹窗；Windows 原生候选已实际播放 KICK 1080p60 并收到聊天。最终发布包与同提交冒烟的结果见 Y01.21。
- Sony Android 9、原反馈掌机、真实禁言事件、Apple 真机交互、Windows 安装版覆盖安装和持续长时间播放仍需验证。iPhone/iPad 模拟器及桌面首页启动不等于这些场景全部通过。
- iPhone、iPad 最低 iOS、iPadOS 15，Mac 最低 macOS 12。苹果平台录制、iPad 系统画中画与台前调度等既有局限沿用 5.4.9。外语文案尚未经母语者校对。

问题和建议请到 [Issues](https://github.com/wzgrx/PureLive/issues) 反馈。
