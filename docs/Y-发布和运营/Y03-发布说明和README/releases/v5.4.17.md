# 纯粹直播 5.4.17（5121）

- 修正macOS窗口被其他应用遮挡时误触发手机后台暂停策略的问题。桌面遮挡和失去焦点保持播放；“设置→视频”新增默认关闭的“最小化窗口时暂停播放”，仅原生最小化事件触发，恢复窗口只继续该策略暂停的会话，手动暂停保留。
- 桌面主直播画面空白处右键可进入／退出窗口内全屏。飞行弹幕动作与控件优先，系统全屏、小窗和多画面原有右键保持。
- 鼠标后退键沿现有返回链优先关闭弹窗、退出房间显示模式或返回页面；首页不请求退出。前进键不映射为返回。

手机后台播放、音量亮度手势和录制内核未修改。原iPhone、Sony/华为电视、Windows偶发白屏与自签设备目录权限问题继续按原反馈取证，不计为本版已修复。正式包哈希及原生验证范围以发布交付回执为准。
