# 纯粹直播 5.4.2（Android、电视、Windows、Linux、macOS、iOS、iPadOS）

5.4.2 重做了小窗：应用里和离开应用后是同一个小窗，可以拖到任意位置、收到边上、无级缩放；macOS 版有了 Mac 自己的标题栏、菜单栏和菜单栏图标；iPhone、iPad 版补上了分享、剪贴板、全屏返回和键盘快捷键。

下载：[Releases](https://github.com/wzgrx/PureLive/releases/latest)，选对应平台的安装包（见文末“下载哪个”）。

## 主要变化

### 小窗（Android）

- **一个小窗**：应用里和应用外是同一个窗口、同一个播放器，进出都不重新加载。
- **点直播间的小窗按钮**：直播间缩成小窗，回到上一页，人还在应用里（以前是进系统画中画，应用退到后台）。
- **离开应用继续看**：小窗开着时回到桌面或切到别的应用，同一个小窗留在其他应用上面，按钮、拖动、改大小、收边都和应用里一样；回到应用时，小窗就在刚才停的地方。这需要“显示在其他应用的上层”权限：设置 → 视频 → 小窗 →“在其他应用上层显示小窗”；没开时小窗先藏起来，回来还在，第一次会提示一次怎么打开。
- **系统画中画改成开关**：设置 → 视频 → 小窗 →“改用系统画中画”（默认关）。以前打开过“离开应用时自动画中画”的，升级后自动打开这个开关，用法和以前一样。“离开应用时自动画中画”改名为“离开应用时自动小窗”。
- **拖动**：能拖到屏幕最上面（状态栏下面）和最下面（手势条上面）；松手后滑到近的一边。
- **收边**：甩到屏幕边上收起，露出一条（至少 56）照常播放，上面有白色竖条；点一下或往里拖就出来，不会触发全面屏的返回手势。
- **改大小**：把手固定在右下角，往屏幕中间或往下拉变大，从 160 宽一直到和屏幕一样宽；两指缩放照旧。弹幕开关和画中画按钮固定在左下角，不再随小窗在屏幕左右换位置。
- **记住位置**：小窗的位置和大小关掉应用再打开也还在。
- **动画**：画面从直播间直接飞进小窗；关闭和回到直播间时先淡出；换页、转屏时平滑挪到新位置。系统里关了动画时都直接到位。

### macOS

- Mac 自己的标题栏（红黄绿按钮），点红色按钮或 ⌘W 只关窗口，应用留在程序坞，录制照常；点程序坞图标窗口回来。⌘Q 才退出，录制中会先问一句。
- 完整的菜单栏：纯粹直播、文件、编辑、显示、播放、窗口、帮助，文字跟应用语言；“播放”菜单在直播间里能暂停、调音量、开关弹幕、纯音频、录制、窗口内全屏。快捷键 ⌘, ⌘F ⌘L ⌘Y ⌘1～⌘4 ⌘[ ⌘W ⌘R。
- 菜单栏图标：平时是单色图标，录制中带红点；设置里可以关掉。
- 用绿色按钮退出系统全屏时，直播间也一起退出全屏；更新下载完有“在访达中显示”。

### iPhone、iPad

- iPad 上的分享从点的按钮旁边弹出（以前会直接失败）。
- 剪贴板：回到应用时只看有没有新内容，不读内容，所以不会弹“允许粘贴”；有新内容时底部提示，点“识别”才读。
- 全屏或开着面板时，从左边缘右滑先退出全屏、关掉面板。
- 新版本对话框里是“去下载页”。
- iPad 接键盘时，⌘ 快捷键和 Mac 相同。

### 其他

- Windows、Linux、macOS 的窗口按保存的大小打开时，不会再比屏幕大。

## 从旧版本升级

- **直接覆盖安装，不要先卸载**：卸载会把数据一起删掉。
- 这一版没有改数据库。新加的设置都有默认值，老用户的用法不变（打开过自动画中画的仍然用系统画中画）。

## 已知问题

- 小窗浮在其他应用上面时，小米 HyperOS 等系统在内存紧张时可能结束应用，小窗随之消失；可以在系统设置里给纯粹直播“无限制”的后台权限。
- macOS、iOS、iPadOS 版仍然只在 GitHub 的构建机和 iPhone 模拟器上打开过，没有在真机上用过；录制在苹果平台上暂时不可用。
- 5.4.1 的其他已知问题照旧：外语译文由 AI 翻译，没有母语者校对；官方登录没有用真实账号逐个登录过；Kick 只在 Android 上能用；HyperOS 划掉应用后可能结束录制和后台播放；Android 15 起录制一天累计最多 6 小时；Windows 安装版没有在测试电脑上安装。

问题和建议请到 [Issues](https://github.com/wzgrx/PureLive/issues) 反馈。
