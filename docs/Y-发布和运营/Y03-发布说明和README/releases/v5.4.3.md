# 纯粹直播 5.4.3（Android、电视、Windows、Linux、macOS、iOS、iPadOS）

5.4.3 补上 iPhone、iPad 的几个系统功能：从别的应用分享直播间进来，退到后台和锁屏后继续播放、锁屏显示正在播放，iPad 接键盘时按住 ⌘ 能看到快捷键列表。其他平台的功能和 5.4.2 相同。

下载：[Releases](https://github.com/wzgrx/PureLive/releases/latest)，选对应平台的安装包（见文末“下载哪个”）。

## 主要变化

### iPhone、iPad

- **从别的应用分享进来**：在浏览器或平台应用里点“分享”，分享面板里有“纯粹直播”；分享直播间链接或带链接的文字，会打开纯粹直播并识别房间，和 Android 的分享一样。分享图片和文件暂时不支持。
- **后台和锁屏继续播放**：回到桌面、切到别的应用或锁屏时声音继续播；锁屏和控制中心显示正在播放的直播间和主播，能暂停和继续。后台时不画画面，回到应用接着画。
- **iPad 快捷键列表**：接键盘时按住 ⌘，系统列出纯粹直播的快捷键（搜索、链接解析、设置、关注、热门、分区、录制中心、历史记录、返回，直播间里还有刷新），文字跟应用语言；iPadOS 26 的菜单栏里也有这一组。

### macOS

- 和 5.4.2 相同。标题栏保持现在单独一行的样子（不再改成按钮和顶栏合在一起）。

## 从旧版本升级

- **直接覆盖安装，不要先卸载**：卸载会把数据一起删掉。
- 这一版没有改数据库，也没有新设置。

## 已知问题

- macOS、iOS、iPadOS 版仍然只在 GitHub 的构建机和 iPhone 模拟器上打开过，没有在真机上用过：分享、锁屏正在播放、后台播放、快捷键列表要等有人在真机上用过才算确认；录制在苹果平台上暂时不可用；iPad 的系统画中画和台前调度还没做。
- 小窗浮在其他应用上面时，小米 HyperOS 等系统在内存紧张时可能结束应用，小窗随之消失；可以在系统设置里给纯粹直播“无限制”的后台权限。
- 5.4.1 的其他已知问题照旧：外语译文由 AI 翻译，没有母语者校对；官方登录没有用真实账号逐个登录过；Kick 只在 Android 上能用；HyperOS 划掉应用后可能结束录制和后台播放；Android 15 起录制一天累计最多 6 小时；Windows 安装版没有在测试电脑上安装。

问题和建议请到 [Issues](https://github.com/wzgrx/PureLive/issues) 反馈。
