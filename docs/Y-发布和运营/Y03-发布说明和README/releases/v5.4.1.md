# 纯粹直播 5.4.1（Android、电视、Windows、Linux、macOS、iOS、iPadOS）

5.4.1 修好了 Linux 版打不开的问题，并第一次提供 5.x 的 macOS、iOS 和 iPadOS 安装包。

下载：[Releases](https://github.com/wzgrx/PureLive/releases/latest)，选对应平台的安装包（见文末“下载哪个”）。

## 主要变化

### Linux 版能打开了

- 5.0.0～5.4.0 的 Linux 包一打开就停在“没能启动”页面（Linux 上没有保存账号的加密方式）。现在用系统自带的 OpenSSL 加密保存 Cookie 和 WebDAV 密码，密钥文件只有自己能读；系统里没有 OpenSSL 时像 3.x 一样不加密保存。
- 第一次打开时会导入 3.x Linux 版的数据（`~/Documents/PURE_LIVE`）。

### macOS、iOS、iPadOS

- macOS 12 起，Intel 和 Apple 芯片通用；iOS、iPadOS 15 起。
- 没有苹果开发者账号，安装包不是苹果签名的：
  - **macOS**：打开 DMG，把“纯粹直播”拖进“应用程序”。第一次打开如果提示“无法验证开发者”，到 系统设置 → 隐私与安全性 → 点“仍要打开”；或者在终端运行 `xattr -cr /Applications/PureLive.app`。
  - **iOS、iPadOS**：用 AltStore 或 SideStore 安装 `ios-unsigned.ipa`（用自己的 Apple ID 签名，免费账号每 7 天要续签一次）；装了 TrollStore 的设备用 `ios-trollstore.ipa`，不用续签。
- 包名和 3.x 相同。从 3.x 的 macOS 版升级，第一次打开会自动导入 3.x 的关注、历史和设置；iOS 用自签工具安装时通常会改包名，数据不能从 3.x 带过来，可以用“设备同步”或备份恢复。
- 界面和 Android、Windows 一样；Mac 风格的菜单栏、标题栏、关窗口不退出，以及 iPad 的专门布局还在做。录制在苹果平台上暂时不可用。

## 从旧版本升级

- **直接覆盖安装，不要先卸载**：卸载会把数据一起删掉。
- 这一版没有改数据库；从 3.x 升级时第一次打开会自动导入 3.x 的数据。

## 已知问题

- macOS、iOS、iPadOS 版只在 GitHub 的构建机和 iPhone 模拟器上打开过首页，没有在真机上用过；遇到问题请在 Issues 里反馈，附上系统版本。
- 5.4.0 的已知问题照旧：外语译文由 AI 翻译，没有母语者校对；官方登录没有用真实账号逐个登录过；Kick 只在 Android 上能用；HyperOS 划掉应用后可能结束录制和后台播放；Android 15 起录制一天累计最多 6 小时；Windows 安装版没有在测试电脑上安装。

问题和建议请到 [Issues](https://github.com/wzgrx/PureLive/issues) 反馈。

## 下载哪个

| 文件 | 适用 |
|---|---|
| `PureLive-5.4.1-5105-debug-signed-android-arm64-v8a-release.apk` | 绝大多数手机、平板和电视盒子（64 位 ARM），不确定就选这个 |
| `PureLive-5.4.1-5105-debug-signed-android-armeabi-v7a-release.apk` | 老的 32 位 ARM 手机、电视 |
| `PureLive-5.4.1-5105-debug-signed-android-x86_64-release.apk` | x86_64 模拟器和设备 |
| `PureLive-5.4.1-5105-windows-x64-setup.exe` | Windows 安装版 |
| `PureLive-5.4.1-5105-windows-x64-portable.zip` | Windows 便携版（解压即用，数据在程序旁边的 UserData） |
| `PureLive-5.4.1-5105-linux-x64.tar.gz` | Linux x86_64 |
| `PureLive-5.4.1-5105-macos-universal.dmg` | macOS（Intel 和 Apple 芯片） |
| `PureLive-5.4.1-5105-macos-universal.zip` | macOS，同上，压缩包 |
| `PureLive-5.4.1-5105-ios-unsigned.ipa` | iPhone、iPad，用 AltStore 或 SideStore 安装 |
| `PureLive-5.4.1-5105-ios-trollstore.ipa` | 装了 TrollStore 的 iPhone、iPad |

Android 包的签名和 3.2.11、4.x、5.x 相同，可以直接覆盖安装。最低 Android 8.0。
