# 5.4.24：直播信息、多端互联与官方回看

- 抖音直播间信息栏接入平台公开的动态与直播预告，支持真实日期、每日/每周循环时间；无需账号登录。入场先取公开消息快照，之后跟随实时更新。平台未提供数据时如实显示暂未收到，不从签名或标题猜时间。
- 电脑多画面增加多屏联动：选择显示器，点击正在播放的格子，在独立窗口全屏观看；后续换房复用该窗口。可通过系统任务视图/调度中心把联动窗口移到其他虚拟桌面。
- 增加局域网遥控：设备发现、二维码和手动地址配对，支持应用或浏览器推送直播间，遥控当前播放器的播放、暂停、换台、音量及导航。接收默认关闭，可随时撤销全部配对。
- 手机横屏多画面支持左侧滑动调亮度、右侧滑动调当前格子音量，退出后恢复应用亮度。
- 直播间增加独立保存的-12到+12dB音量增益，支持清除本房间覆盖、恢复全局默认；与音量滑块分开。
- 工具箱和电视链接页增加斗鱼官方回看与视频：推荐、分类搜索、作者分页、同场分段、清晰度、进度拖动、本机续播和历史、时间轴弹幕及弹幕设置。受平台权限限制的清晰度不能播放，签名地址不写入历史。
- Android增加与其他媒体同时播放的可选开关，保留来电、系统中断和耳机断开处理；实际共播仍受系统及其他应用音频策略影响。
- 电视房间列表与控制栏的主播信息更醒目，长标题在聚焦时滚动显示。
- 自动跳转下一直播间前，先对当前直播间做两次完整刷新并等待恢复，降低卡顿或短暂黑屏导致的误跳转。
- 修正底层播放器所有实例共用操作队列的问题：旧播放器停止或释放未返回时，不再同时堵住替换播放器的初始化和控制。保留每个实例内部的串行操作与原生资源释放保护。
