- 分区平台标签增加图标。导航设置增加安卓滚动隐藏导航栏及手机底栏、桌面侧栏文字开关，新设置保留原有默认行为。

- Windows 直播主画面空白处可用鼠标中键切换窗口内全屏，控件和弹幕保持各自操作。
- iOS 识别备份中的旧容器默认录制目录并使用当前系统 Documents 解析；保留自定义目录和原配置，不搬移或删除文件。
- 升级稳定工具链与依赖，纳入 Flutter 官方语义树修复，修正本轮实际观察到的 Windows 无障碍树崩溃。
- 调整弹幕正则耗时检查，减少系统调度暂停导致的误拒，原有时间预算保留；增加播放缓冲状态诊断。
