# 纯粹直播 5.4.18（5122）

- 统一手机设置中 IPTV、录制、本地互动、备份与日志的切换方式，沿用设置页内的即时切换及返回位置。
- 修正电视本地配置预览打开手机双栏的问题；七个设置页统一电视页头、壁纸背景、初始焦点、方向键边界及滚动跟随。配置预览可用方向键滚动，右键进入控件、左键返回滚动区。
- 修正电视首次启动菜单已有焦点却不显示焦点框的问题。
- 手机与桌面分区平台标签增加现有平台图标，保留名称和排列。
- “设置→导航”增加安卓滚动隐藏上下导航栏（默认关闭）、手机底栏和桌面侧栏文字显示（默认开启）。返回顶部、切换页面和尺寸变化恢复导航。
- Windows 直播主画面空白处鼠标中键可进入／退出窗口内全屏；控件与弹幕优先，保留右键和手机原操作。
- iOS 识别从备份带来的旧容器默认录制路径，使用系统当前 Documents 解析；自定义目录和原始配置值保留，不搬移或删除旧文件。此项保护不代替原自签手机的录制验收。

原华为／Sony 电视播放、自签 iPhone 录制和 Windows 偶发窗口异常继续保留跟踪；尚未取得原设备复测，不计为本版已解决。
