# 纯粹直播 5.4.9（Android、电视、Windows、Linux、macOS、iOS、iPadOS）

5.4.9 补齐多画面和全屏播放控制，修复电视首选直播平台操作，并为 iPad 增加原生音量、亮度手势支持，改善播放防息屏的恢复与重试。

下载：[Releases](https://github.com/wzgrx/PureLive/releases/latest)，按文末“下载哪个”选择安装包。直接覆盖安装，保留原有数据，不必卸载。

## 主要变化

- **多画面一键静音**（[#21](https://github.com/wzgrx/PureLive/issues/21)）：沉浸和全屏模式右上角增加静音按钮，桌面端支持 M 快捷键；再次操作恢复原有各画面音量。输入框或弹层中不会误触快捷键。
- **电视首选直播平台**（[#22](https://github.com/wzgrx/PureLive/issues/22)）：TV 模式改用遥控器选项列表，方向键切换、确认键保存，返回键取消，避开手机版搜索框。
- **全屏醒目留言入口**（[#23](https://github.com/wzgrx/PureLive/issues/23)）：有活动 SC 时显示按钮，到期自动隐藏；可在弹幕设置关闭。手机和电视沿用当前直播间会话内最多 500 条的历史显示/隐藏，不跨会话保存。电视面板同时调整 720p、1080p、4K 的内容缩放与焦点。
- **iPad 音量、亮度手势**（[#24](https://github.com/wzgrx/PureLive/issues/24)）：接入 iOS 原生设备控制，支持播放画面手势调节；离开播放或切后台恢复此前亮度，进入页面和读取音量不主动改变系统音量。
- **播放防息屏**（[#25](https://github.com/wzgrx/PureLive/issues/25)）：补充生命周期恢复、失败重试和定期检查，串行处理唤醒锁，避免退出后被延迟请求重新打开。
- **斗鱼故障定位**（[#15](https://github.com/wzgrx/PureLive/issues/15)）：导出日志新增安全的失败阶段标记，区分详情、清晰度和播放地址；不记录账号、Cookie 或原始接口内容。

## 已知问题与验证范围

- iPad 两项修改已完成源码回归和 Apple 原生编译验证，尚无反馈设备的实际验收；模拟器启动不代表 iPad 真机亮度或防息屏已验证。升级后如仍异常，请在对应 issue 补充复现步骤和日志。
- 索尼电视的实际遥控器、真实付费 SC 和 Windows 安装版覆盖安装未逐项验收。发布包检查与各端启动结果见 Y01.20；本版功能新增 13 项回归，电视 SC 同时覆盖多分辨率布局和焦点。
- 斗鱼登录后无法播放（[#15](https://github.com/wzgrx/PureLive/issues/15)）、小横屏侧栏（[#14](https://github.com/wzgrx/PureLive/issues/14)）继续跟踪；本版增加诊断，不宣称这两个问题已解决。
- Windows KICK（[#26](https://github.com/wzgrx/PureLive/issues/26)）仍待网络通道与真实播放、弹幕验证，本版未开启。
- iPhone、iPad 最低 iOS、iPadOS 15，Mac 最低 macOS 12。苹果平台录制、iPad 系统画中画与台前调度仍待支持，其他已知限制沿用 5.4.8。外语文案尚未经母语者校对。

问题和建议请到 [Issues](https://github.com/wzgrx/PureLive/issues) 反馈。
