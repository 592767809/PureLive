# 5.5.0：应用遥控、屏幕共享与播放信息

- 局域网遥控扩展到应用内的首页、列表、搜索、设置和弹窗，支持方向、确认、返回、首页及当前输入框文字输入。
- 新增单独本机授权的屏幕查看与镜像；可在配对浏览器截图、录制屏幕画面并下载到控制设备。仅共享画面，不采集麦克风或系统声音，文件由用户自行保存和编辑，没有自动反馈上传。
- 镜像停止或断开后回到并刷新原直播间；原先暂停的房间保持暂停。配对撤销、旧会话回调与并发启停均按会话归属清理。
- 手机、桌面和电视共用时间/当前直播流输入速率信息层，可关闭、跟随控制栏或常驻，支持四角、字体、字号和颜色。
- 修复手机玻璃底栏遮挡关注分区按钮、电视识别异常后缓存为手机、设置面板左右退出及滑块上下导航、更新源和下载完成弹窗初始焦点问题。
- 电视设置目录首行按上键保持焦点，向下滚动后回到首行时重新显示标题；左键仍可返回设置菜单。
- 统一桌面独立设置页面的正文对齐、宽度与标题；新增默认开启的“记住上次窗口”，应用指定开机尺寸后切换为固定尺寸，普通拖动不改写预设。


- 斗鱼登录请求未取到直播流时，对当前公开房间尝试游客线路；保存的 Cookie 和其他房间保持原样，游客也失败则保留原错误。
- Windows 卸载前等待本安装目录下的进程保存状态、停止录制并退出；无法关闭时中止卸载，保留应用文件及用户数据。
- 新增默认关闭的“B站尝试 Raw 原画”：仅在原画可用且有超清档的转码房间尝试同源与 204 候选，失败回退官方线路，不改动未转码房间。

原#33/#47/#49仍按维护者决定暂缓，当前受控验证不宣称这些原设备故障已解决。候选包的原生验证范围和未覆盖条件见Y01.39发布记录。
