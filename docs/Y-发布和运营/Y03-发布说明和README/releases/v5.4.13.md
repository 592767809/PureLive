# 纯粹直播 5.4.13（Android、电视、Windows、Linux、macOS、iOS、iPadOS）

5.4.13 修正电视升级弹窗的遥控器焦点和设置菜单焦点框边距。

## 主要变化

- **电视升级弹窗**（[#37](https://github.com/wzgrx/PureLive/issues/37)）：更新说明有可见焦点，长说明可用上下键滚动，到边界继续按方向键即可离开说明区并到达操作按钮，不再陷入文本选择区域。OK 在说明区不触发安装；项目链接、跳过版本、其他下载方式、取消和更新入口保留。
- **电视设置焦点框**（[#39](https://github.com/wzgrx/PureLive/issues/39)）：统一电视设置分组和整行的宽度与圆角边界，移除焦点框外多出的一圈间距；整行不放大、描边留在视口内，保留防裁切修正。手机布局保持原样。
- **壁纸重试反馈**（[#38](https://github.com/wzgrx/PureLive/issues/38)）：请求失败后点击重试，立即显示加载状态，避免旧错误页一直停留；请求进行中不会重复排队，再次失败时恢复重试按钮。本项不代表原电视连接失败已修复。
- **斗鱼签名兼容性**（[#15](https://github.com/wzgrx/PureLive/issues/15)）：签名轮数解析从最多 16 次提高到有界的 4096 次，修正较高次数被提前拒绝的兼容缺口。保留过期、无效字段和超限校验；实际受影响账号仍需升级复测，问题继续开放。
- 保留 5.4.12 关注页分级返回和既有多画面、播放诊断改进。

## 仍在跟踪

- Wallhaven 壁纸库 [#38](https://github.com/wzgrx/PureLive/issues/38)：本机公开 API 返回 24 条，缩略图和原图片段可读；尚未复现原电视超时，不将网络取样成功写成修复。继续收集原设备错误类型。
- 华为智慧屏 [#33](https://github.com/wzgrx/PureLive/issues/33)：新增日志是 buffering_stall_timeout 和零尺寸画面，仍不足以判定网络或解码器根因；继续开放。
- 受影响斗鱼账号 [#15](https://github.com/wzgrx/PureLive/issues/15)：新日志已定位到本地签名轮数范围拒绝；本版提高有界上限，仍待受影响账号升级复测，继续开放。

## 验证范围

修改前会失败的遥控与实际像素回归已保留；修正后定向检查通过。完整门禁、同提交十包、各端启动图与 K90 v4dev 的最终结果分别记录在 Y01.24。原 Sony 电视与遥控器、Apple 真机、Windows 安装覆盖和长期播放仍不等同于模拟与本机验证。

问题和建议请到 [Issues](https://github.com/wzgrx/PureLive/issues) 反馈。
