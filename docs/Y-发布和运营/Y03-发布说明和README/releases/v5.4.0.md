# 纯粹直播 5.4.0（Android、电视、Windows、Linux）

5.4.0 的界面有了 15 种语言：简体中文、繁體中文、English、日本語、한국어、Español、Français、Deutsch、Português、Русский、Italiano、Tiếng Việt、ไทย、Bahasa Indonesia、Türkçe。另外新增“音量增强”，给声音比平台 App 小的直播间加几分贝。

下载：[Releases](https://github.com/wzgrx/PureLive/releases/latest)，选对应平台的安装包（见文末“下载哪个”）。

## 主要变化

### 15 种界面语言

- 设置 → 外观 → 语言，可以选上面 15 种。没选过时跟随系统语言；系统是台湾、香港、澳门的中文时用繁体。
- 繁体中文由简体转换而来，用台湾的常用词（例如“影片”“資訊”）。
- 中文以外的语言，人数用 K、M 表示（不用万、亿）。
- 外语界面里平台名用拉丁字母写法（Bilibili、Douyin、Huya 等）。
- 某个词还没有翻译时，外语界面显示英文，繁体界面显示简体。

### 音量增强

- 设置 → 视频 → 音量增强：关闭、+3、+6、+9、+12 dB。直播间、多画面、电视和音乐播放都生效。
- 实测抖音、快手、虎牙、哔哩哔哩的直播流本身就比平台 App 的输出小，纯粹是原样播放，平台 App 自己调大了声音。觉得小声时打开；本来就响的直播间开太大会破音。

### 修复

- 本地弹幕的输入框：文字和提示现在在输入栏正中，不再偏上。
- 在设置里切换界面语言后，首页等留在后面的页面立刻换成新语言，不用重启。

## 从旧版本升级

- **直接覆盖安装，不要先卸载**：卸载会把数据一起删掉。
- 这一版没有改数据库，5.x 和 4.x 的数据原样使用；从 3.x 升级时第一次打开会自动导入 3.x 的数据。之前选过的语言（简体中文或 English）照旧。

## 已知问题

- 外语译文由 AI 翻译，没有母语者校对，可能有不自然的说法；欢迎在 Issues 里指出。
- 平台自己给的文字（直播间标题、分区名、公告等）仍是平台原文。
- 5.3.0 的其他已知问题照旧：官方登录没有用真实账号逐个登录过；Kick 只在 Android 上能用；HyperOS 划掉应用后可能结束录制和后台播放；Android 15 起录制一天累计最多 6 小时；Windows 安装版没有在测试电脑上安装。

## 以后要做的

- iOS、iPadOS、macOS：需要 Mac 构建和签名，以后再做。

问题和建议请到 [Issues](https://github.com/wzgrx/PureLive/issues) 反馈。

## 下载哪个

| 文件 | 适用 |
|---|---|
| `PureLive-5.4.0-5104-debug-signed-android-arm64-v8a-release.apk` | 绝大多数手机、平板和电视盒子（64 位 ARM），不确定就选这个 |
| `PureLive-5.4.0-5104-debug-signed-android-armeabi-v7a-release.apk` | 老的 32 位 ARM 手机、电视 |
| `PureLive-5.4.0-5104-debug-signed-android-x86_64-release.apk` | x86_64 模拟器和设备 |
| `PureLive-5.4.0-5104-windows-x64-setup.exe` | Windows 安装版 |
| `PureLive-5.4.0-5104-windows-x64-portable.zip` | Windows 便携版（解压即用，数据在程序旁边的 UserData） |
| `PureLive-5.4.0-5104-linux-x64.tar.gz` | Linux x86_64 |

Android 包的签名和 3.2.11、4.x、5.x 相同，可以直接覆盖安装。最低 Android 8.0。
