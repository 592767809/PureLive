# 5.4.21：手势、贵宾人数与主页按钮

- 电视端链接放映新增“用手机输入”，同网扫码粘贴直播间链接或分享口令即可打开，无需同步关注。
- 修复主页回到顶部/底部箭头被玻璃底栏遮挡，标准和紧凑底栏、安全区、平板与导航隐藏状态统一避让。
- 修复横向滑动时少量纵向偏移误调音量、亮度；正常竖滑统一从按下位置计算位移，保留延迟读取和竖屏操作。
- 斗鱼贵宾人数移至直播间信息栏、详情及电视控制栏，随弹幕连接实时更新，不再以周期性聊天消息刷屏；贵宾数独立保存于当前会话，不影响真实在线人数和排行。

华为智慧屏、部分旧Android设备黑屏及特定Windows启动白屏仍需原设备验证，本版不宣称这些报告已解决。
