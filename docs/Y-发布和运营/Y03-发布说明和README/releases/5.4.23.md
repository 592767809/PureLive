# 5.4.23：失败播放后的恢复与黑屏修复

- 修复Android画面Surface先到、初始选项后到时把有效输出覆盖为空的问题。
- 打开操作卡住或持续没有播放进度时，隔离失效内核并进行有上限的恢复；旧房间迟到的操作不会覆盖新房间。
- 修复快速切房时音量命令排队导致打开超时失效，以及重建播放器后画面组件仍订阅旧播放器、内核播放但屏幕黑的问题。
- 原生状态读取改为有超时的异步请求，区分属性不可用、读取异常和超时；增加有限的恢复诊断信息。

已用Android 9独立模拟器和生成媒体核对失败后返回、长停顿重建与手动换线，并检查实际屏幕画面。Sony与Honor原设备及真实平台取流波动尚未复验，#49继续跟进，不据模拟器结果宣称所有设备彻底修复。
