# 纯粹直播 5.4.11（Android、电视、Windows、Linux、macOS、iOS、iPadOS）

5.4.11 增加多画面“1×4 竖排”，便于在竖屏显示器从上到下观看四个直播间，并补充播放失败诊断信息。

## 主要变化

- **多画面竖排**（[#32](https://github.com/wzgrx/PureLive/issues/32)）：在布局栏选择“1×4”，四路画面按顺序从上到下排列，保持 16:9；切换布局、缩放窗口和进入全屏保留播放会话与声音选择，重开后记住布局。手机窄屏可以左右滑动布局选项。原四宫格默认值不变。
- **播放失败诊断**（[#33](https://github.com/wzgrx/PureLive/issues/33)）：日志补充播放器最终失败的固定分类、解码模式和视频尺寸状态，便于区分媒体连接、解码和输出问题；不记录媒体地址、请求头、账号或异常原文。

## 已知问题与验证范围

- 华为智慧屏 HEGE-550“只有弹幕，没有画面和声音”仍在定位，尚未确认根因；本次补充诊断，不宣称已修复，#33 保持开放。请提供失败画面和“设置 → 数据 → 日志”中的 playback-engine-failure / recovering 行，勿发送登录凭据。
- 斗鱼登录账号取流问题 #15 仍等待受影响账号反馈，继续开放。
- Windows/Linux/macOS 的多画面共用布局实现；合成布局测试和原生实测分别记录。原智慧屏、Apple 真机、Windows 安装覆盖、长时间多路播放仍待验证。iPhone/iPad 模拟器启动不能替代真机验收。
- iPhone、iPad 最低 iOS、iPadOS 15，Mac 最低 macOS 12。苹果平台录制、iPad 系统画中画与台前调度等既有局限沿用上一版。

问题和建议请到 [Issues](https://github.com/wzgrx/PureLive/issues) 反馈。
