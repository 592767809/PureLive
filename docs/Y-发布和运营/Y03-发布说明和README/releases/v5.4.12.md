# 纯粹直播 5.4.12（Android、电视、Windows、Linux、macOS、iOS、iPadOS）

5.4.12 修正电视关注页返回键的焦点层级，先回到上方筛选，再返回左侧菜单。

## 主要变化

- **电视关注页分级返回**（[#35](https://github.com/wzgrx/PureLive/issues/35)）：房间卡片和离线行按返回键，先恢复最近使用的状态或平台筛选；再按返回才到左侧菜单。保留选中的平台、直播状态和标签。
- 标签筛选行和空列表操作也先回上方状态／平台筛选；只有一个平台时回状态筛选。侧栏上的返回继续显示退出确认，其他页面沿用原来的返回方式。
- 5.4.11 的 1×4 竖排多画面与播放器安全分类日志继续保留。

## 已知问题与验证范围

- 华为智慧屏 HEGE-550 无音视频问题 [#33](https://github.com/wzgrx/PureLive/issues/33) 仍等待原设备日志，继续开放；不将本版焦点修正写成播放修复。
- 受影响斗鱼账号的登录取流问题 [#15](https://github.com/wzgrx/PureLive/issues/15) 继续跟踪。
- 修改前失败的焦点回归、页面／Android 原生返回通道和各端原生启动分别核验，最终结果见 Y01.23。K90 电视界面测试与原反馈盒子、遥控器的验收分别记录；Apple 真机、Windows 安装覆盖和长期播放尚未覆盖。
- iPhone、iPad 最低 iOS、iPadOS 15，Mac 最低 macOS 12。苹果平台录制、iPad 系统画中画与台前调度等既有局限沿用上一版。

问题和建议请到 [Issues](https://github.com/wzgrx/PureLive/issues) 反馈。
