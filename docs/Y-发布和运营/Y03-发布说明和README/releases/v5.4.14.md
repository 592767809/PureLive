# 纯粹直播 5.4.14（Android、电视、Windows、Linux、macOS、iOS、iPadOS）

## 主要变化

- **多画面直接换台**（[#43](https://github.com/wzgrx/PureLive/issues/43)）：沉浸和全屏模式右键／长按一格后，在音量下方直接显示搜索、关注／历史和房间列表，与普通宽屏模式一致。右键哪一格就替换哪一格，其他空格不再作为默认目标；选台后关闭面板并保持当前模式。已播放房间继续选中已有格，其他格的会话与音量保留。原换台图标和 Esc／返回保留。
- **短窗口与大字**：控制区和列表可以分别滚动；侧栏的音量百分比按实际字体留出宽度，避免放大后折行。紧凑竖屏手机仍保留原底部控制面板与换台图标。
- 保留 5.4.13 的电视焦点、iOS 手势时序、Apple 录制能力与斗鱼签名兼容修正。

## 仍在跟踪

- 斗鱼 [#15](https://github.com/wzgrx/PureLive/issues/15)：小米 13 用户已反馈 5.4.13 登录播放恢复；冷启动及离开房间后的复测、其他账号／Windows 情况继续核对。
- 华为智慧屏换房 [#33](https://github.com/wzgrx/PureLive/issues/33)、原 iPhone 手势 [#41](https://github.com/wzgrx/PureLive/issues/41)、自签 iPhone 直播录制／导出 [#42](https://github.com/wzgrx/PureLive/issues/42) 仍待原环境复测，保持开放。
- Sony Wallhaven [#38](https://github.com/wzgrx/PureLive/issues/38) 已由反馈者自行关闭：其补充确认在该网络下 API 需要代理才可达；原电视失焦不据此声称已验收。
- 构建期间新增菜单首项焦点框 [#46](https://github.com/wzgrx/PureLive/issues/46) 和 Windows 偶发启动白屏 [#47](https://github.com/wzgrx/PureLive/issues/47)，已分别评估回复，保持开放；本版没有声称修正这两条。

## 验证范围

保留旧实现缺少直接列表及大字百分比折行的失败回归；两个显示模式、深浅主题、替换目标、重复房间、其他会话、返回链、短窗口 2 倍系统文字和竖向窗口的定向检查通过。完整门禁、同源十包与各端原生结果分别记录在 A13.5／Y01.25，不将合成布局截图扩大为真实播放、全部设备或长期多路验收。

问题和建议请到 [Issues](https://github.com/wzgrx/PureLive/issues) 反馈。
