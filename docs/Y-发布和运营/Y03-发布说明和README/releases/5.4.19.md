# 5.4.19：自动换台与反馈修复

- 新增关注列表自动换台，默认关闭。主播确认下播或现有恢复流程失败后选择下一位在线关注；多画面独立换台、避免重复、保留声音来源。暂停、断网恢复和睡眠定时优先，候选耗尽停止。
- 修复播放会话迟到的停止和超时影响新房间、重试错误漏处理；设备发现遇到异步网络错误时保留其他同步路径。
- 修复新装直接进入IPTV设置缺少默认列表、电视统计栏被滚动裁切；电视备份“更多”、平台选择器首焦点和完整描边可用。
- 热门与分区统一平台图标和选择器；分区“网络”直接展示IPTV频道，手机分区图片更紧凑；电视房间列表优先显示频道/直播标题。
- 弹幕字号上限提高到60；新增默认关闭的斗鱼贵宾人数通知开关；修复关闭长按交互后长按被当作点按。
- Windows中键切换系统全屏，右键保持窗口内全屏。
- 更新页统一电视样式和遥控操作；修复版本与包信息不一致，增加安装包精确大小/SHA-256及严格续传检查。缺少摘要的历史包通过浏览器下载。

自动换台首阶段仅使用关注列表，热门/分类候选暂不包括。原Sony/Huawei音视频异常与Windows特定显示器组合白屏尚无原机闭环，不将通用修复当作这些报告全部解决。
