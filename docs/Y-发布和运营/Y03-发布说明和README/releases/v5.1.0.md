# 纯粹直播 5.1.0（Android、电视、Windows、Linux）

5.1.0 把 5.0.0 说“以后再做”的电视功能补齐了：电视界面多了视频和音乐两个模式、壁纸、电视样式的设置，直播浏览页按新设计重做；开播提醒可以按主播单独开关，Android 上应用被系统清理后也会提醒。

下载：[Releases](https://github.com/wzgrx/PureLive/releases/latest)，选对应平台的安装包（见文末“下载哪个”）。

## 主要变化

### 电视：三个模式

导航栏最上面的模式按钮可以在“直播 / 视频 / 音乐”之间切换，切到哪个模式导航栏就换成那个模式的入口。

- **视频**（哔哩哔哩点播，需要登录，没登录时可以扫码登录）：首页（动态、推荐、热门）、分区、影视（番剧、国创、电影、电视剧、纪录片、综艺）、我的（UP主、稍后再看、收藏夹、历史记录、追番、追剧）、搜索（视频、用户、番剧、影视）。详情页焦点在“播放”，看过的写“继续 P2 · 01:46”，可以点赞、投币、收藏、稍后再看，下面是相关视频。播放器：画质、倍速、弹幕（设置和直播间一样）、字幕、选集、评论都在右侧面板；←→ 快退快进，连按加大步长，↑↓ 换集；本机和云端都记进度。
- **音乐**（哔哩哔哩音频和视频里的歌）：正在播放、搜索、歌单、推荐、我的五个入口。播放器有封面和滚动歌词、队列面板、列表循环 / 单曲循环 / 随机、纯音频或显示画面、标准 / 无损；离开播放器音乐继续放，通知栏和媒体键可以控制。歌单可以新建、重命名、同步收藏夹，也能从网易云、酷狗、QQ 音乐导入歌单（逐首匹配）。进直播间或看视频时音乐自动停。
- 直播还是原来的直播模式。

### 电视：壁纸

- 电视界面的背景可以换成纯色、渐变、图片或视频：图片来自必应每日壁纸、Wallhaven（只要适合全家看的图）和随机壁纸，视频壁纸输入一个视频地址，下载后静音循环。
- 可以调填充方式、遮罩深浅和模糊程度，先在预览里看效果，按“设为背景”才保存；进直播间、看视频时视频壁纸自动暂停。

### 电视：设置

- 电视样式的设置目录：电视自己的设置（界面模式、焦点放大、壁纸、导航栏）在最前面，手机的各个设置分节按电视的样子显示，选项用电视的选择框和颜色格子。
- 导航栏显示控制：每个模式的入口可以排序、隐藏、换图标。
- “扫码到手机”：要输入 Cookie、地址这类长文字，或看日志时，电视上显示二维码，用同一局域网的手机打开网页填写或查看；打开外部链接也改成显示二维码。

### 电视：直播浏览按新设计重做

- 关注：状态（已开播 / 录播 / 未开播）和平台放在一行并带个数；未开播的关注是两列紧凑行，不再是大封面。
- 分区：关注的分区单独成一页；分区卡片长按弹出小窗（打开、关注 / 取消关注），不会一按就关注；分区房间页顶上有“＋ 关注”。
- 热门：平台标签最后多了“全部平台”面板。
- 观看记录：显示条数和保留数量，可以刷新是否在播、改保留数量，按日期筛选。
- 搜索合成一页：直播间 / 主播、包含未开播、排序、搜索范围都在搜索框下面，结果在最下面；主播结果是紧凑行；可以“用手机输入”；清空最近搜索先确认。

### 开播提醒

- 每个主播可以单独开关开播提醒：关注页、直播间的关注按钮菜单里都能设，设置里能看到开了几个、一键清除。
- Android：应用被系统冻结或从最近任务里划掉后，系统大约每 15 分钟让应用后台检查一次开播（新设置“后台检查”，默认开）。小米、红米手机需要在应用信息里允许“自启动”。

## 从旧版本升级

- **直接覆盖安装，不要先卸载**：卸载会把数据一起删掉。
- 这一版没有改数据库，5.0.0 和 4.x 的数据原样使用；从 3.x 升级时第一次打开会自动导入 3.x 的数据。
- 新设置都有默认值：电视模式默认“直播”，后台检查开播默认开，壁纸默认不换。

## 已知问题

- 新功能通过了自动测试，在 K90 手机上做了快速测试；电视的视频、音乐、壁纸、设置只在手机的电视模式下测过，没有在电视真机上测。遇到问题请反馈。
- 视频和音乐只接了哔哩哔哩；音乐的无损需要账号有对应权益。
- 后台检查开播的时间由系统决定，可能晚于 15 分钟；省电模式下可能更久。
- 5.0.0 的其他已知问题照旧：Kick 只在 Android 上能用；HyperOS 划掉应用后可能结束录制和后台播放；Android 15 起录制一天累计最多 6 小时。
