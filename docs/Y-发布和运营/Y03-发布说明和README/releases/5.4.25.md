# 5.4.25：播放初始化与Windows启动修复

- 修复播放器初始化超时后反复等待同一个挂起实例的问题。失败初始化会隔离，重试可创建替代实例；未释放资源有数量上限。
- 修复原生停止挂起时换房继续复用旧播放器的问题。旧房的迟到停止、初始化和清理不会影响新房；退出播放也有明确等待上限。
- 修复播放器初始化配置失败时的资源清理，补充不含播放地址和账号信息的原生阶段日志。
- 修复Windows恢复位置/最大化与首帧绘制之间的异步竞态，避免原生首帧显示再次覆盖保存的窗口状态；增加有限的启动期Flutter子窗口尺寸再同步。

#33、#47、#49的应用缺陷已有回归修复；Huawei/Sony电视、Honor9X和原GTX760电脑仍待原设备复验，本次不将受控故障或模拟器结果等同于原设备彻底解决。
