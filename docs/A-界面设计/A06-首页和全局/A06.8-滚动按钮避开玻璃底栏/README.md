# 滚动按钮避开玻璃底栏

用户反馈主页的上滑箭头与底栏玻璃重合。关注页和热门/分区房间列表均使用共享JumpButtons。列表已通过GlassBarInset为浮动胶囊留位，按钮仍固定在页面底部16像素处。

共享按钮读取同一GlassBarInset，整体上移底栏实际覆盖高度。支持标准/紧凑胶囊、Android手势/三键、iOS安全区及平板底栏。普通底栏自行占据布局空间，额外避让为零；自动隐藏玻璃栏后恢复原位置，保留列表滚动状态。

仅修正既有按钮布局；48像素点击范围、上下跳转、玻璃样式、导航设置与列表透过玻璃滚动均保持原行为。无新增设置或翻译。

参照Flutter官方[extendBody说明](https://api.flutter.dev/flutter/material/Scaffold/extendBody.html)及已有[A01.5](../../A01-设计系统/A01.5-液体玻璃/README.md)。本任务属于小范围布局修复，按用户持续自主维护授权执行。
