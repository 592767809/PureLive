# A06.7 导航滚动隐藏和文字开关

## 范围与方案

安卓首页向上滚动隐藏上下导航、向下恢复，设置可关且默认关闭；底栏文字默认显示，桌面侧栏文字默认显示，保留图标、语义和提示。只响应当前可见主页垂直用户滚动，切换页面/设置/旋转恢复，不影响直播、横向分页和程序滚动。

## 决策

按D-003由维护者选择建议A：复用当前组件、背景、设置、返回和窗口内全屏。新设置默认保持现状；本次授权来自用户明确要求解决并发布。没有取得新的旧库门禁例外。

## 执行和验收

先读AGENTS、PROCESS、ENGINEERING和UI规范及关联任务；保留当前3.x设置含义。修复需有修改前失败回归；完成后跑定向与全量门禁、对应端实际交互及截图。仅操作已授权的K90 v4dev和Windows隔离副本；保留数据与正式版。无原机证据的旧问题保持开放，不根据搜索结果盲改。发布按Y01.29逐项核验。

补充真实状态栏验收：导航隐藏后，四个主页内容仍须避让系统状态栏、侧边缺口和底部系统操作区；普通/玻璃、单入口/多入口一致，显示恢复不重建当前页面。
