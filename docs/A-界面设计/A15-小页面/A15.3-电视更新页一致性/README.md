# A15.3 电视更新页一致性

## 范围和原因

接 A15.2，处理 [issue #70](https://github.com/wzgrx/PureLive/issues/70) 的电视外壳与遥控器操作。更新元数据一致性和下载完整性分别由 Y02.2、Y02.3 处理，不在这里重做。

电视路由的在线更新、版本历史没有使用设置页的 `TvSettingsScaffold`；共享页面直接构建手机 `AppBar`，导致背景、页头和返回入口不一致。复用既有电视设置外壳和共享页头作用域，不引入新设计，不改变手机、平板和桌面的现有布局。

## 要保留的行为

沿用 A15.2 的状态卡、包列表、下载源、复制、发布页、历史详情及下载确认顺序。所有更新和下载仍使用已有服务，不访问真实平台进行自动测试。刷新、错误重试和异步完成不能把焦点抢离覆盖对话框；返回逐级关闭详情和对话框。

## 验收边界

自动化验证覆盖电视路由、主题背景、无重复页头、默认焦点、方向键到达操作、焦点可见性、加载和失败恢复、窄宽布局及普通模式回归。完整仓库门禁通过后才能提交；原 Sony 设备和发布包另行验收，自动测试不能替代。

## 定向回归发现的补充问题

- 历史列表的选中背景不能代替焦点框：列表项按真实焦点单独绘制电视描边。
- 电视详情中的 `SelectionArea` 会截获方向键：定向导航模式只排除其焦点，保留普通模式选择行为；对话框也按导航模式判断。
- 长说明没有可供遥控器逐段阅读的焦点入口：历史详情局部复用 `KeyboardScrollArea`，覆盖有限高度的整个详情区域，包含退出阅读所需的页头操作。控制器随版本详情销毁；普通模式不显式注入控制器，保留 `PrimaryScrollController` 继承。
- 放大字体时包状态徽标溢出：`SettingsRow` 的自定义尾部值增加弹性约束，不改变数据、顺序和可用操作。

更新页长说明也复现连续方向键不能滚动，使用包含刷新页头的有限阅读区域，仅在定向导航且说明非空时启用；无发布页 URL 或下载包时仍可退出阅读到刷新。普通模式保持隐式滚动控制器。更新页用稳定的 Scaffold 标识在阅读外壳增删时保留刷新焦点，不主动抢占覆盖对话框。

这些改动均由定向失败用例引出，不修改共享电视焦点跟随算法。更新页与历史页分别验证，不能相互推定通过。
