# A07.30 桌面直播画面中键全屏

## 范围与方案

Windows主画面空白处鼠标中键沿用窗口内全屏往返；控件、弹幕、锁定、PiP、多画面和手机原交互优先。按下与释放按钮/目标一致且取消不触发。

## 决策

按D-003由维护者选择建议A：复用当前组件、背景、设置、返回和窗口内全屏。新设置默认保持现状；本次授权来自用户明确要求解决并发布。没有取得新的旧库门禁例外。
