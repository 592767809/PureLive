# A07.26 小窗把手、拖动范围和收边

- 编号、状态、档位、规模：以登记表为准，见[子分类页](../README.md)和 [STATUS.md](../../../STATUS.md)
- 类型：界面
- 来源：用户 2026-10-17 K90 上：“1.应用内小窗 右下角设计的是什么功能，点击这个没反应，2.小窗以后，移动小窗 不能移动到手机最上面和最下面，是有什么限制吗？3.小窗移动到手机侧边，只露出1/5画面，设计不错，但是……全面屏手势，把在侧边的小窗拉回正常画面，很容易触发返回的手势，需要重新设计一下逻辑和设计”；“不能无极放大缩小了，用户操作”（改大小保持无级，由用户拖）
- 相关：A07.22、A07.24

## 改动

1. 角上的把手是“拖动调整小窗大小”（A07.22，无级），以前点了没反应、也看不出：点一下弹出这句提示；拖动照旧无级改大小。
2. 小窗刚出现时仍让开状态栏、底部手势条和首页底栏（各留 16）；用户拖过以后，上面可以到状态栏下沿，下面可以到系统手势条上沿（可以盖住首页底栏）。只改大小不算拖过。
3. 收在侧边时露出的部分加宽系统返回手势占的宽度（K90 两边各约 30），手指可以在手势区外抓住它；收边的那一条还从系统返回手势里排除（Android 10 起 `systemGestureExclusionRects`），拉回来不会触发返回；点一下照旧拉回来。
