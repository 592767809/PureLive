# A07.31 鼠标中键系统全屏分离

来源：[issue #75](https://github.com/wzgrx/PureLive/issues/75)。

## 问题与范围

Windows 直播主画面空白处的中键与右键都调用窗口内全屏，且共用仅允许普通布局和窗口内全屏的判断，因此中键既不能进入系统全屏，也不能从系统全屏退出。

中键改为单独调用系统全屏入口；右键继续切换窗口内全屏。共用画面命中保护，不增加全局鼠标监听，不修改窗口管理原生实现、播放会话、设置或其他平台操作。

## 状态约定

| 当前状态 | 中键 | 右键 |
|---|---|---|
| 普通布局 | 进入系统全屏 | 进入窗口内全屏 |
| 窗口内全屏 | 进入系统全屏 | 恢复普通布局 |
| 系统全屏 | 恢复普通布局及系统窗口 | 保持原状，不切换窗口模式 |

F、双击和全屏按钮保持原行为：从普通布局进入全屏，从窗口内全屏退出到普通布局。Esc 仍先关面板，再退全屏。系统退出全屏以及离开直播间仍走已有恢复逻辑。

控件、输入框、弹窗、弹幕、锁定、小窗和多画面不被新的中键动作接管；非 Windows 不增加中键映射。取消、拖动、组合按键和按下后改变按钮不算中键点击。

## 验证边界

回归检查使用真实直播页和假播放器，不访问真实直播平台。窗口状态通知和标题栏可由组件测试检查；Windows 原生全屏、任务栏、普通窗口位置大小和最大化恢复必须另行实际验证，不能由模拟状态代替。
