# A07.31 修复范围与验收

## 修改范围

- 直播页：为 Windows 中键提供独立系统全屏动作，复用现有进入、退出和恢复逻辑。
- 主播放器：中键与右键分开判断允许的显示状态，保留原命中和手势优先级。
- 直播页回归：使用已有公开接口验证中键系统全屏与右键窗口内全屏的差异，并可对修改前代码执行。

不改 F、双击、右键、返回链、小窗、多画面的既有约定，不修改原生窗口库、版本号或更新源。

## 验收

1. 普通布局中键进入系统全屏，再次中键退出；播放器与会话不重建。
2. 右键窗口内全屏往返不改变系统全屏状态；窗口内全屏可由中键直接进入系统全屏，退出后恢复普通布局。
3. F、双击、Esc、系统退出和关闭直播间继续正确恢复；Esc 优先关闭面板。
4. 可见控件、输入文本及选择、弹幕、弹窗、锁定和小窗优先；取消、拖动和组合按钮不触发；非 Windows 不增加中键行为。
5. 记录修改前真实失败、修复后定向测试、分析及完整门禁结果；Windows 普通/最大化窗口原生往返单独记录，未验证项不写通过。
