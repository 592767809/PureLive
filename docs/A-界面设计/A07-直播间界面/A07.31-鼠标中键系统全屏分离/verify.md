## Windows 实际验收（未执行）

1. 记下普通窗口位置与大小。直播主画面空白处中键进入系统全屏：画面填满屏幕，窗口标题栏及任务栏不遮挡。再次中键恢复原位置、大小和普通布局，重复三次。
2. 将窗口最大化，重复中键往返；退出后仍最大化，而不是变成普通大小。
3. 普通和最大化窗口各做右键往返：仅播放器布局改变，系统窗口边界不改变。
4. 右键进入窗口内全屏，再中键进入系统全屏，再中键退出：回到普通布局，窗口恢复进入前的普通/最大化状态。
5. 核对 F、双击和 Esc；先打开面板再按 Esc，只关闭面板，第二次退出全屏。中键和右键不抢控件、输入选择、弹幕菜单、弹窗、小窗或多画面操作。
6. 中键按下后取消、拖动或加按其他按钮；快速连续往返及关闭直播间，窗口与页面状态不残留。
