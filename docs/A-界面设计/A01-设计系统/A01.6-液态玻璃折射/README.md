## 用户看到的

- 首页底栏默认是悬浮的液态玻璃胶囊（设置“液体玻璃”仍可关掉，回到普通底栏）：
  - 页面从下面透出来，边缘像透镜一样把后面的内容往里弯，带一点色散；
  - 左上方向的光在边上打出一道细高光，对面一道淡的；
  - 背景轻度模糊、按主题色着色，饱和度略提高。
- 选中项是一颗更透的玻璃水滴，下面的内容放大约 1.12 倍：
  - 点别的项，水滴带弹簧滑过去（稍微过冲再停稳，约 0.35 秒），跑得快时被拉长、压扁一点；
  - 按住底栏左右拖，水滴跟着手指走（过了两端越拖越沉），每跨过一项轻震一下，松手吸到最近的一项（带上甩出的速度）；
  - 再点一次当前项照旧刷新关注（3.x）。
- 设备不支持着色器滤镜（没有 Impeller）时是毛玻璃底栏加浅色水滴；内存 4 GB 及以下的手机是不模糊的半透明（同 A01.5）。

## 怎么做的

- 着色器 `packages/live_ui/shaders/liquid_glass.frag`，作为背景滤镜（`ImageFilter.shader`，外面再套一层 4 的模糊）。底栏和水滴两个圆角矩形用距离场在着色器里算，坐标是屏幕物理像素：在 K90 上用探针应用验证过，背景滤镜里的 `FlutterFragCoord` 是全屏坐标、输入纹理是整屏。
- `packages/live_ui/lib/src/widgets/liquid_glass_bar.dart`：`LiquidGlassBar`、`RenderLiquidGlass`（每次绘制按 `getTransformTo` 算出在屏幕上的位置；所在路由的转场动画一动就重画，页面推入推出时形状跟得上）、`LiquidGlassShader`（只加载一次，不支持时为空）。
- 水滴的弹簧 `AppMotion.dropSpring`（刚度 520、阻尼比 0.72）；拖动过头用 `AppMotion.rubberBand`。
- 读背景的区域比玻璃大一圈（16）：只读玻璃本身时模糊和折射把区域外的透明混进来，上沿出现一道暗线（K90 上看到后改的）。
- 精度用 highp：屏幕 2608 像素高，mediump 定不准行，边缘出现横纹（K90 上看到后改的）。
- 无障碍：每项是一个按钮节点，大小正好是水滴静止时的位置（够 48 高、对比度按它下面的颜色算）；文字一律 onSurface（主题色字在玻璃上只有 4.26:1）。
