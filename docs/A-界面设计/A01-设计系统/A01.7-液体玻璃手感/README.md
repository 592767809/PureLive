# A01.7 液体玻璃手感：照酷安的底栏改按下、移动和回弹

- 编号、状态、档位、规模：以登记表为准，见[子分类页](../README.md)和 [STATUS.md](../../../STATUS.md)
- 来源：用户 2026-10-20：“值得学的这些还有动画和手感、流畅度、彻底借鉴的地方，这些可以更新过来吗？”
- 相关：A01.5（液体玻璃）、A01.6（着色器折射）；参考对象是一加 13 上的酷安 16.6.2（只读分析：Compose 外壳 + 开源库 Kyant Backdrop，Apache-2.0，`Kyant0/AndroidLiquidGlass` 的 `LiquidBottomTabs` 示例）

## 酷安的底栏（2026-10-20 实测，120 帧录屏逐帧）

- 选中项平时是灰色药丸（浅色 10% 黑、深色 10% 白），**只在按下或移动时变成透镜**：折射、放大、色散和边缘高光随按下程度出现，到位后变回药丸。
- 按下：药丸长到 78/56 倍，宽和高各一根欠阻尼弹簧，所以会来回收放；整条胶囊同时放大 16 dp；手指处有一团柔光。
- 点另一项：约 25 ms 变透镜开始走，约 170 ms 到位，约 290 ms 停稳。
- 按住拖动：透镜跟手（弹簧追手指），按速度横向拉长、纵向压扁（最多 ±20%）；整条胶囊顺着拖动方向偏 4 dp，松手弹回。
- 透镜里的图标是选中色，透镜外是普通色，图标在透镜边缘一半变色。
- 流畅度：20 秒操作 1440 帧，卡顿 1.04%，帧耗时中位 9 ms、P90 11 ms、P99 21 ms；动画期间满 120 帧。

## 我们的做法

| 项 | 之前（A01.6） | 现在 |
|---|---|---|
| 水滴静止时 | 一直是透明放大的玻璃 | 灰色药丸（10% 黑或白），按下、移动时才是透镜 |
| 按下 | 固定时长 160 ms 进、260 ms 出 | 弹簧：按下进度（1, 1000）；宽（0.6, 250）、高（0.7, 250）各一根，长到 78/56 |
| 去下一项 | 弹簧 dropSpring（0.72, 520），会冲过头 | 弹簧（1, 1000），不冲过头；形状的收放来自宽高和速度的弹簧 |
| 拖动 | 直接设位置 | 弹簧追手指；两端照旧越拉越沉 |
| 按速度变形 | 速度/2400 拉长，最多 45% | 速度经欠阻尼弹簧（0.5, 300）平滑，横向 ÷(1−0.75v)、纵向 ×(1−0.25v)，各最多 20%；停下时反向收放一次 |
| 整条胶囊 | 不动 | 按下放大 16 px；拖动时偏移最多 4 px，松手弹簧（1, 300）回位 |
| 图标颜色 | 按离水滴的距离渐变 | 两层图标：普通图标只在水滴外，选中色实心图标只在水滴内（按水滴的实际形状裁剪）；名字一份，选中加粗 |
| 高光 | 只有边缘反光 | 按下时整条加一层淡光，水滴处一团柔光（叠加混合） |
| 着色器 | 水滴只在胶囊里画 | 胶囊和透镜的并集都画（按下的透镜比胶囊高）；透镜边缘色散是胶囊边缘的 2.5 倍；胶囊的边缘反光只在胶囊里 |
| 关掉动画（系统） | 不动画 | 一直是药丸，直接到位 |

参数在 `packages/live_ui/lib/src/theme/motion.dart`（`glass*Spring`、`glassHeldScale`），实现在 `packages/live_ui/lib/src/widgets/liquid_glass_bar.dart` 和 `packages/live_ui/shaders/liquid_glass.frag`。

## 验证

- `packages/live_ui/test/liquid_glass_bar_test.dart`：按住变透镜、松手回药丸、整条放大；点另一项时以透镜过去、停稳成药丸；关掉动画时一直是药丸；每项一个名字、一对图标。
- 真机：K90（Impeller）看浅色、深色的按下、点按、拖动和长按，录屏逐帧对比酷安；帧耗时对比。
