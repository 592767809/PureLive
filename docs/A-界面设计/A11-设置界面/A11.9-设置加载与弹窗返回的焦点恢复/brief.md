# A11.9 任务书

修复 TvSettingsScaffold 在首次加载期间被弹窗覆盖、关闭弹窗后无首行焦点的问题。先加入真实 Navigator、异步内容、Dialog 的失败测试，再修改生命周期。保留已选中的行、返回层级和 header 排除规则；不能让后台页面抢焦点。

验收覆盖：内容延迟出现；弹窗覆盖与返回；首次聚焦后用户移动焦点再开关弹窗；页面卸载不再回调。相关设置回归和完整 all/14 必须通过，原生电视操作另记。用户此前将手机测试延后，按当前授权先完成其他平台。

补充K90发现的可视区域验收：异步数据替换后，在869×400和1920×1080两种尺寸，首行必须位于实际滚动视口内；Down/Up双向移动后仍可见，已可见行不持续跳动，过期焦点回调不能滚动新页面。

补充共享Material按钮验收：电视设置内五种按钮在真实焦点处显示统一边框，包含全局touch高亮模式；失焦和禁用保留原样式，不能改变手机／桌面全局高亮策略。
