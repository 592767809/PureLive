# A11.8 设置页面导航与电视外壳统一

## 范围与方案

同一设置内容复用既有页面和电视外壳；手机五个入口与分类同帧切换；电视七页单栏、首焦点、上边界、可滚动和壁纸背景一致。深链与宽屏双栏保留。

## 决策

按D-003由维护者选择建议A：复用当前组件、背景、设置、返回和窗口内全屏。新设置默认保持现状；本次授权来自用户明确要求解决并发布。没有取得新的旧库门禁例外。
