# A12.8 电视备份文件操作：验证清单

设备、系统、构建版本及结果：**待记录；以下均未做真机验证**。

1. 使用测试包进入电视设置 → 备份与恢复；创建完整备份和仅关注备份。
2. 只用方向键逐行到备份文件，右移到更多按钮，确认打开菜单；返回后焦点仍在更多按钮，左移回主体。
3. 文件主体短确认打开预览；返回不改数据，焦点回主体。菜单键和长确认打开原菜单；持续按住并松开不能自动进入恢复预览或删除。
4. 完整备份菜单保持恢复全部、仅恢复关注、删除；仅关注备份没有恢复全部。两类菜单均能上下选择。
5. 选择删除先取消，文件仍在且焦点返回；再确认删除，有其他文件时焦点落到剩余文件，最后一个删除后落到备份目录。
6. 恢复预览期间，所有文件及更多按钮变灰不可用；取消恢复后重新可用。
7. 损坏/无法读取的备份恢复失败后提示原错误，焦点恢复，仍可再次打开更多菜单。文件被外部删除时确认删除，不应留下无效焦点或异常。
8. 无备份、目录读取失败及重试状态仍能由方向键到达可用操作。
9. 手机点击/长按、电脑点击更多/右键仍为同一菜单；窄横屏和宽屏没有文字或按钮溢出。

记录真实遥控器的确认、菜单和返回行为；若厂商“设置”键映射不同，单独记录键码，不以鼠标测试代替。
