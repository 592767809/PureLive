# A12.8 电视备份文件操作：记录

- 日期：2026-10-27。
- 来源：issue #71；根因与实现见 [README.md](README.md)。

## 改动

1. 电视文件主体与更多按钮采用相邻焦点目标，沿用设置行内容和已有菜单。
2. 复用 `TvFocusable` 的短确认、长确认及菜单键；保护菜单复入与开菜单的确认键尾部事件。
3. 等待预览/删除动作完成后恢复原焦点；文件消失后转到剩余文件或备份目录。
4. 备份操作繁忙时文件与更多入口同时禁用；保留删除确认和错误提示。
5. 新增 6 个遥控按键回归：方向可达、菜单/长确认/短确认区分、重复释放保护、取消和成功恢复返回、删除最后文件、删除后剩余文件、恢复失败、文件已被外部移除和目录无写权限时的删除失败；同时断言更多按钮的语义标签、按钮和点击动作。

## 测试发现及修正

首次运行完整备份测试为 21 项通过、3 项失败：一项测试语义句柄释放晚于测试框架检查；另两项是真实的最后文件消失后焦点错误。Flutter 在方向导航模式下仍允许空状态 `SettingsRow` 的 `InkWell` 成为焦点候选，因此不能只按“第一个可遍历节点”选择回落位置。现已仅在仍有文件时选择文件区，否则选择备份目录；语义测试在 `try/finally` 内释放句柄。后续上述 70 项均通过。
