# A12.8 电视备份文件操作（接 A12.4）

- 来源：[GitHub issue #71](https://github.com/wzgrx/PureLive/issues/71)。
- 范围：备份与恢复 → 目录中的备份；补齐遥控器操作，不改变备份格式、WebDAV 或全局导航。
- 状态：见 [record.md](record.md)；真机步骤见 [verify.md](verify.md)。

## 根因

`apps/pure_live/lib/features/backup/backup_page.dart` 的 `_BackupFileRow` 把更多按钮放进 `SettingsRow.trailing`。`packages/live_ui/lib/src/widgets/settings_row.dart` 的可用行由整行 `InkWell` 获得焦点，按钮的中心仍在整行焦点矩形内。Flutter 的方向遍历按当前矩形边界筛选候选点，因此右键方向不能进入这个嵌套按钮。可用行并没有被 `ExcludeFocus` 排除；禁用行中的 `ExcludeFocus` 不是此问题的根因。

原来的 `GestureDetector.onLongPress` 只处理指针长按，没有把遥控器确认键长按或菜单键转为同一个菜单。原来的 `_usable(_Action.file)` 还会让恢复期间其他文件行继续显示可用，尽管底层动作会被并发保护拒绝。

## 行为

| 入口 | 结果 |
|---|---|
| 文件主体短按确认 | 原有恢复预览 |
| 文件主体右方向键 | 更多按钮独立获得焦点；左方向键回主体 |
| 更多按钮确认、主体或按钮菜单键、长按确认 | 同一个备份菜单 |
| 菜单取消、恢复预览取消、恢复读取失败 | 回到打开菜单的主体或更多按钮 |
| 删除确认取消 | 保留文件，回到原目标 |
| 删除后尚有文件 | 焦点转到第一个剩余备份 |
| 删除最后一个文件 | 焦点转到备份目录 |
| 任一备份操作进行中 | 文件主体和更多按钮均禁用 |

电视只把原有设置行内容和更多按钮拆成相邻的遥控焦点目标，使用现有 `TvFocusable` 的确认、菜单、长按处理。手机点击、长按和电脑右键路径保留。菜单打开时消耗尚未松开的确认键重复和释放事件，避免长按后误执行第一项恢复操作。菜单复入受保护；恢复和删除仍沿用原来的预览、确认及错误提示。

删除后回落只在仍有备份时选文件区。方向导航模式下空状态行也可能是 Material 的焦点候选，因此最后一个文件消失时明确转到备份目录，不把空状态文字当成可操作目标。

## 基线及边界

3.x 的创建、恢复及仅关注数据语义不变；A12.4 已确定的预览、文件菜单、删除确认及指针操作保留。没有新增设置或翻译键。测试使用临时合成备份，不访问直播平台。

尚未验证的边界：Android TV/盒子厂商的“设置”键若没有映射为 Android 菜单键，需要真实设备确认；不能把普通 widget 按键测试视为真机结果。没有改变全局按键映射。
