# A16.6 应用级遥控记录

- ApplicationRemote接入当前根路由，播放页命令优先；首页、设置、搜索、列表和弹窗可方向/确认/返回/首页导航。
- 输入只能写入当前同一个可编辑字段；页面/焦点版本变化使旧命令失效，状态不导出已有文字；原生自有电视输入框保持窗口和字段归属。
- 原生测试发现焦点位于WidgetsApp外层，补入当前根Navigator路由焦点范围；五项回归包括覆盖弹窗保持归属。Android16浏览器方向+OK实开菜单再进入设置，正常文字写入搜索框且未提交搜索。
- 采集系统授权期间阻止网络输入，镜像覆盖时仅镜像页面接收导航；控制整台设备/其他软件不在本应用范围。
