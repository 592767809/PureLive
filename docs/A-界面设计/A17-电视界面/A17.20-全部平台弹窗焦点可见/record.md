# A17.20 记录

## 2026-10-27 候选实现

实现第一项自动聚焦、选中态独立、私有滚动控制器与关闭清理、带焦点及挂载检查的逐项可见性处理；根据按钮最大宽度计算两侧绘制留白。保持按钮的 1.05 倍放大和 3 像素外描边。

新增 6 条定向回归：重复打开、确认与返回恢复；1080p、720p 字号提升、矮窗口及窄窗口下，纯方向键逐项遍历和反向滚动、整圈几何和四侧像素、关闭保留原值以及背景标签不随动。测试不访问平台，使用离线预检和内存存储。

## 静态审查

初始焦点、选中态、滚动所有权和销毁保护符合范围，水平留白按最大单元格宽度计算是保守上界。测试包含 720p、1.5 倍字号下放大开与关；运行时和原机结果仍需验证。

## 验证结果

工具链：Flutter 3.47.8、Dart 3.13.7。

- 修改前：6 条新回归全部在有效断言失败。首次打开聚焦已选平台而不是第一项；1080p 的右侧描边超出视口约 3.57 逻辑像素，720p 关闭放大时底部描边仍超出约 1.66 像素；其他放大、矮窗口和窄窗口场景也复现边缘裁剪。
- 修改后：6 条新回归全部通过，包含每项方向键导航、反向滚动、实际变换后的绘制边界和四侧像素、确认 / 返回 / 关闭、重复打开及快速销毁。
- 相关电视目录：137 条测试全部通过；`live_ui`：246 条测试全部通过。
- 初轮静态分析的 5 条提示已修正；应用和 `live_ui` 的 `dart analyze --fatal-infos` 均无问题。清理后重新执行 6 条定向回归，全部通过。
- Dart 格式化、文档检查和差异空白检查通过。首项和末项的合成画面已检查，测试字体不能用于真实中文排版验收。
