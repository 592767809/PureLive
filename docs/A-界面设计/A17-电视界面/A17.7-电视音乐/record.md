# A17.7 电视音乐：开发记录

## 2026-10-15（5.1.0）

- 照搬旧分支 M14.4 的：
  - `e5a6ede7f` 的音乐设置：`musicPlayMode`（列表循环）、`musicAudioOnly`（开）、`musicResumeOnOpen`（关）、`musicProgressLine`（开）、`musicLossless`（关）、`musicCacheLimitMb`（1024）、`musicThirdPartyEndpoints`（空 = 默认）。设置分节 `music` 归 A17。
  - `MetaStore.entries(prefix)`（按前缀读）。
  - `f712f2bd9` 的逻辑：`app/music_catalog.dart`、`music_library.dart`（歌单、喜欢、最近、收藏夹同步、每日推荐、歌词链）、`music_player.dart`（一个播放会话放整个队列、三种模式、缓存、失败跳过）。只改了引用的位置。
  - 它的界面没有用，照新设计重写。
- 媒体会话：
  - 用直播的 `RoomMediaNotification`（同一个 audio_service 处理器）。新加 `showTrack`、`updateTrack`：上一首、播放 / 暂停、下一首、拖动进度。直播的 `show`、`update` 一点没改。
  - 离开播放器音乐继续放，通知栏和媒体键可以控制。
  - 切走音乐模式、进直播间、看视频时停音乐（`yieldMusicToOtherPlayback`）。
- 模式和五个入口：
  - 模式按钮多了“音乐”。
  - 正在播放、搜索、歌单、推荐、我的。切到音乐默认进“我的”。
  - 前面是视频模式同一个登录门；每个页面底下有迷你播放条（队列不空时出现）。
- 组件：
  - 一个歌曲行（g2），正在放的一首用主色。
  - 一个歌曲菜单（g6）：下一首播放、加入队列、喜欢、加入歌单、UP 主主页。移除按位置写“从队列移除”“移出歌单”“从最近播放移除”“从喜欢的歌曲移除”。焦点在第一项。
  - “列表循环 ⌄”（g3）在播放器、队列面板各一个。
  - 加入歌单（g7）：已有的写“已在”，“新建歌单并加入”建完就把歌加进去。
- 播放器（g4、g5）：
  - 封面和歌词（当前句高亮、自动滚动；“正在加载歌词…”“暂无歌词”），关掉纯音频时显示画面。
  - 进度条和一行控制栏：播放、上一首、下一首、模式、纯音频 / 显示画面、音质（标准 / 无损）、喜欢、队列。
  - 在进度条上按 ↑ 打开队列面板；返回先关面板，再离开，音乐不停。
- 歌单：
  - 喜欢的歌曲、自建歌单、同步的收藏夹。
  - 新建、重命名、删除（先确认）、同步收藏夹。
  - 歌单详情的焦点在“播放全部”（g11）。
- 导入歌单：
  - 第 1 步：选网易云 / 酷狗 / QQ 音乐，输入链接或编号。
  - 第 2 步：逐首匹配，显示进度，可以停止。
  - 第 3 步：完成，匹配到的歌建成新歌单。
- 推荐：
  - 每日：先选一个哔哩哔哩收藏夹作来源，有“换一批”。
  - 动态：本机关注的 UP 主的新投稿。
  - 排行。
- 我的（g9）：
  - 两个“UP主”分开：“关注的UP主”是本机关注，加专辑；“B站关注”是账号的关注。
  - 最近：清空先确认，焦点在“取消”（g8）。
  - 云端：删除一条先确认。
- 测试：
  - `test/tv/tv_music_test.dart`，5 个用例：歌曲菜单的焦点和移除文字；“已在”和“新建歌单并加入”；迷你播放条和“列表循环 ⌄”；两个 UP 主的名字和清空最近先确认；导入三步。
  - `tv_test` 的模式用例加了“音乐默认在‘我的’”。
  - `live_store` 新增一个用例：音乐设置和按前缀读。

## 和设计的差别、没做的

- 歌单页是列表行，不是 6 列 / 4 列网格（Y3）。
- 音质用选项框，不是贴着按钮的小菜单（g4）；“播放内核”不放在音乐里（只有 Mpv）。
- 多选、歌词手动选择、“打开时继续上次播放”（设置在，界面入口还没有）没做。
- 缓存上限和第三方地址的设置页没有加（设置项已有）。

## 要在电视上看的

- 登录过哔哩哔哩的电视：排行里放一首，迷你播放条出现；进播放器后有封面和歌词。
- 离开播放器再换入口，音乐继续放；遥控器媒体键、通知栏能暂停和切歌。
- 模式切回直播，音乐停止。
- 导入一个网易云歌单链接。
