# A17.3 电视直播浏览：开发记录

## 2026-10-15（5.1.0）

- 关注（c2、c3、c4）：
  - 状态“已开播 / 录播 / 未开播”和平台放在一行，中间一条分隔线，每个标签带个数；分组标签一行在下面。
  - 未开播的关注是两列紧凑行（头像、主播、平台、上次的标题，`TvRoomRow`），不再是大封面。
  - 空状态文字照手机，操作说明换成遥控器的说法。
- 分区（c5、c6）：
  - 分区和关注分区分开：导航栏多了“关注分区”（在“分区”后面，心形图标）。
  - 分类是次级标签样子；平台只有一个分类时不显示分类行。
  - 分区卡片长按（或菜单键）弹小窗：打开、关注 / 取消关注（`showTvAreaDialog`），不再直接关注。
- 分区房间（c7）：顶栏副标题“平台 · 分类”，右边“＋ 关注 / ✓ 已关注”。
- 热门（c8）：平台标签最右多了“全部平台”，打开 3 列平台面板，可以去“平台显示”。
- 观看记录（c9、c10）：顶上一行“共 n 条 / 保留 m 条”、刷新（重新核对是否在播）、保留数量（20 / 50 / 100 / 200 / 不限 / 自定义）、清空（先确认）；平台标签；按日期分。
- 搜索（c11、c12）：
  - 合成一页：搜索框；下面一行“直播间 / 主播”、“包含未开播”、排序（只在直播间模式）、“用手机输入”；再下面一行说明（手机的范围说明，OK 打开“搜索范围”面板）；平台标签（含“全部”）；结果在最下面。
  - 主播结果是两列紧凑行，第二行“平台 · 正在直播 / 未直播”，不再把头像放大当封面。
  - 结果里按上键回到平台标签；切“直播间 / 主播”、换平台、改范围会用同样的词重搜。
  - 结果都是未开播又被隐藏时，提示并给“显示未开播结果”。
  - 最近搜索“清空”先确认，焦点在“取消”；长按删一条照旧。
- 测试：
  - `test/tv/tv_browse_test.dart`，4 个用例：关注一行状态和平台、未开播两列行；分区长按小窗和关注分区页；热门“全部平台”面板；观看记录的个数、保留数量和日期。
  - `tv_test` 新用例：搜索一页的筛选、主播结果是行、上键回平台、清空先确认；原来的搜索用例照新布局通过；导航栏个数改了。

## 和设计的差别、没做的

- 观看记录的日期是一行次级标签（“全部”加手机的日期分组），不是网格里的日期小标题：电视网格按行列走焦点，插标题会打乱行列。
- 分区长按小窗用了 A17.1 的对话框，和手机的小菜单内容一样，样子是电视的。
- 搜索的“用手机输入”是一个按钮，按了才开局域网服务、弹二维码（A17.9 的扫码到手机），不是一直显示在右边：省得一进搜索页就开着服务。
- “搜索范围”面板直接用手机的面板（A09.7），没有另画电视版。
