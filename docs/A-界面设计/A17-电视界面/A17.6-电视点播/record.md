# A17.6 电视点播：开发记录

## 2026-10-15（5.1.0）

- 阶段 0，外挂音轨（G 组，单独提交 `c54461a82`）：
  - `live_player` 的 `EngineMedia.audio` 和 `PlaybackRequest.audio` 在每次打开时，给这条线路配上自己的 DASH 音频。mpv 用 `audio-files`，以 `change-list` 方式整条加入。
  - 照搬旧分支 M14.3（`e6dd43c8f`）的做法；它的倍速部分没要，5.0 已经有了。
  - 测试：`session_test` 两个用例：分开的流每条线路都带自己的音频；没有音频回调时（直播）和以前完全一样。
- 模式（A17.2 X1）：
  - 导航栏最上面加模式按钮（直播 / 视频）；新设置 `tvMode`（默认 live）。
  - 每种模式有自己的入口，导航栏显示控制按当前模式编辑。
  - 删掉“视频、音乐、壁纸”三个“建设中”占位：壁纸在设置里（A17.8），音乐随 A17.7。
- 视频模式五个入口（X4）：
  - 搜索：输入框、最近搜索、大家在搜，结果分视频、用户、番剧、影视。
  - 我的：UP主、稍后再看、收藏夹、历史记录、我的追番、我的追剧。
  - 首页：动态、推荐、热门。
  - 分区：16 个分区，标签只写文字。
  - 影视：番剧、国创、电影、电视剧、纪录片、综艺。
- 登录门（验收 12）：没登录时视频模式整块是登录门。“扫码登录”打开直播的哔哩哔哩扫码页（同一份 Cookie）。
- 数据：
  - `app/vod.dart` 和 `tv/video/video_source.dart`（`VideoSource` 接口）、`video_store.dart`（本机进度、搜索历史、播放偏好）取自旧分支 M14.3，修了编译。
  - 旧分支的界面没有用，照新设计重写。
- 卡片（c5）：`TvVideoCard`，和直播房间卡片同一外框、同一焦点。封面上有时长、角标、看过的进度条；番剧卡片同一外框。
- 列表（c6、c7）：一个标签栏（`TvTabBar`），一种分页网格（`TvVideoGrid`），状态用 A17.1 的组件：首次加载用骨架，出错写原因加“重试”，空的写下一步。
- 卡片弹窗（c16、c17）：长按确认或菜单键弹出，动作写明（稍后再看、某某的主页、删除这条记录、取消追番、取消关注）。删除、取消追番、取消关注都先确认。
- 详情页（c3、c4）：
  - 焦点在“播放”，看过的写“继续 P2 · 01:46”。
  - 单 P 不列分 P；分 P 写“看到 01:46”。
  - 点赞、投币、收藏（选收藏夹）、稍后再看、UP 主主页、评论；下面是相关视频。
  - 按钮放在封面右边，第一屏就能看到。
- 番剧页（c9）：焦点在“第1话”（看过的那一集优先），会员集带标记，可以追番和取消追番。
- UP 主空间（c18）：“＋ 关注 / ✓ 已关注”，取消要确认；排序“最新发布 ⌄”，可选最新发布、最多播放、最多收藏。
- 播放器（c12～c15）：
  - 控制栏两组一行放下，没有快退、快进按钮；播放图标跟着状态变；用不了的按钮变灰。
  - 画质用选项框，倍速循环切换。
  - 弹幕设置、评论、选集都在右侧面板，不挡画面；弹幕设置用直播间同一个 `DanmakuSettingsContent`。
  - 点播弹幕按播放时间分段加载、上屏；字幕显示在下方；顶上写在线人数；控制栏收起后底边有进度线。
  - 遥控器：←→ 快退快进，800 毫秒内再按依次 10、20、30、60 秒；↑↓ 换集；确认显示控制栏；返回逐层退出。
  - 本机进度和云端历史每 15 秒上报一次（心跳），失败不影响播放。
  - 看视频时视频壁纸暂停。
- 评论（c15）：一个评论组件 `TvVideoComments`，用在播放器面板和评论页：热门 / 最新、加载更多、空、出错。
- 测试：
  - `test/tv/tv_video_test.dart`，6 个用例：登录门；首页三个标签、卡片和出错重试；详情页焦点、单 P、继续；番剧第 1 话、会员标记；历史删除先确认；播放器（DASH 带外挂音轨、控制栏一行、没有快退快进、在线人数、控制栏收起和进度线）。
  - `tv_test` 新增“模式按钮切到视频”。

## 和设计的差别、没做的

- 画质用居中的选项框，不是贴着按钮的小菜单（c13）。
- 评论只读：不能发评论、不能看楼中楼。
- “稍后再看”的删除、收藏夹的管理只做了最常用的。
- pure_live_TV 设计基线之后新加的点播功能没有做，以后先进 V01。

## 要在电视上看的

- 需要登录过哔哩哔哩的电视：画质切到 1080P 后有声音（外挂音轨）、画面变清楚。
- ←→ 连按加速，↑↓ 换集，返回逐层退出。
- 看到一半返回，详情页写“继续”；“我的 · 历史记录”里有这一条。
