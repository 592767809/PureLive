# A17.28 记录

来源：https://github.com/wzgrx/PureLive/issues/138

已查看报告的三张图片，并在受控API28电视模式复现：设置目录第一行按上键跳到左侧“直播”模式项。默认几何导航会选择标题旁更高的菜单项，现有菜单恢复还排除了模式项；默认ensureVisible只揭示第一条可聚焦行，不含其上方不可聚焦标题，滚回后残留189逻辑像素偏移。设置目录第一行现显式保留上键，左键仍返回设置菜单；第一行重新获焦时在当前帧布局后恢复到滚动起点，带回页面和分组标题。只影响目录第一行，不改变其他页面或子页滑块的方向语义。

原生旧试包的焦点前后层级与截图已保留。两条最终反证均在旧目录失败：上键离开首行及回顶残留189像素；修复后两条通过。原测试等待100毫秒不足以完成120毫秒既有焦点动画，最终断言等待一秒，且用同一断言重新验证旧代码失败。最终同源包复验和发布待完成。

trial4受控Android9电视模式已确认首行上键停留、下滚回顶标题恢复及左键返回设置菜单。共享设置滑块的方向模式焦点与整行可见性也补上反证和修复；最终同源包仍需复验。

trial6受控Android9电视模式原生复验并亲自查看六份截图：首行上键停留、回顶标题恢复；HUD选项为电视布局且常驻项默认聚焦，上键确认后成功持久化跟随控制栏；字号18→19→18、音量50→55→50及整行焦点框通过。实际软件解码测试流在控制栏隐藏时无HUD、OK后显示时钟和输入速率。仅为当前源码试包，最终冻结提交另行重建、核对和复验；不代表原Sony设备验收。
