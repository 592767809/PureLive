# A17.21 链接放映手机输入

来源：[issue #98](https://github.com/wzgrx/PureLive/issues/98)。电视端搜索已有手机扫码输入，链接放映仍只有遥控器输入，长链接难以输入。复用TvPhoneBridge的一次性局域网表单，在“播放”旁增加“用手机输入”，不用同步关注或登录账号。

手机页面提供多行粘贴，初始值来自现有输入；提交后调用同一个ToolboxController解析短链接、房间链接、分享口令并打开TV房间。取消和空白提交保留已有内容；解析失败保留可编辑文本；解析时禁用再次发送，离开后忽略晚到结果。按钮采用Wrap随宽度换行，沿用电视焦点和图标。复用既有协议，不新增持久服务或平台弹幕发送。
