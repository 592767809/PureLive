# A17.19 电视首屏焦点状态恢复

## 范围与方案

复现首次进入菜单展开时已聚焦节点保留、焦点控件被重建后内部状态丢失。直接以实际FocusNode状态绘制，保持菜单/页面焦点和手机桌面规则。

## 决策

按D-003由维护者选择建议A：复用当前组件、背景、设置、返回和窗口内全屏。新设置默认保持现状；本次授权来自用户明确要求解决并发布。没有取得新的旧库门禁例外。
