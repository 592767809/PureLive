# A17.8 电视壁纸：开发记录

## 2026-10-15（5.1.0）

- 敏感来源（D-032）：
  - 随机壁纸去掉了“性感美女”整组，以及无铭 API 里的美囡、黑丝、白丝、抖音美女和唯美女生图片，还有 360 壁纸的“美女”“明星”“时尚”“萌娃”等以人物为主的分类（也去掉了“军事”“爱情”）。
  - 其余照 pure_live_TV。
  - Wallhaven 只要适合全家看的图（`purity=100`），也不要人物类。
  - 测试 `tv_wallpaper_test` 逐个检查这些词都不出现。
- 壁纸库没有照搬 pure_live_TV。它的壁纸库调用的是 iTab 浏览器扩展的私有接口，请求里冒充那个扩展的来源和指纹，所以不用。改用两个公开、有文档的来源：
  - 必应每日壁纸（最近两周）；
  - Wallhaven 公开 API（热门、最新、风景、动漫、随机）。
- 视频壁纸 pure_live_TV 也来自 iTab，这里改成输入一个视频地址：下载到本地后静音循环播放。
- 设置（`live_store`，只加不改）：
  - `tvWallpaperKind`（默认 none，和以前一样）、`tvWallpaperValue`、`tvWallpaperSource`；
  - `tvWallpaperFit`（默认等比覆盖）、`tvWallpaperMask`（默认 35%）、`tvWallpaperBlur`（默认关）。默认值照 pure_live_TV。
- 背景层（h1）：
  - 在 `TvAppFrame` 里，导航器下面，所以所有电视页面后面都是它。
  - 设了背景时 `TvTheme.backdrop` 为真，各页面不再画自己的底色（首页、分区房间、搜索、设置页），面板、设置行、卡片保留自己的底色（h8）。
  - 没有背景时和以前完全一样。
- 模糊（h7，Z2 A）：
  - 静态图在设为背景时模糊一次，存成 PNG（最宽 1920），放在应用支持目录 `tv_wallpaper/`。运行时不再逐帧模糊。
  - 换模糊程度时，从原图重新算一次；同样的模糊值不会重复算。
  - 换背景或清除时，删掉旧文件。
  - 解不出的图按原样显示。
  - 视频壁纸选模糊时会提示“视频壁纸不能模糊”。
- 预览（h2、h3，Z1 A）：
  - 底部按钮写“填充 · 等比覆盖”“遮罩 · 35%”“模糊 · 关闭”。
  - 在预览里调的只作用在预览上；按返回不改正在用的背景；按“设为背景”时连同这些一起保存。
  - 随机壁纸多一个“换一张”。
  - 预览里的模糊是临时的 `ImageFiltered`，只在预览页用。
- 沉浸式（h6）：隐藏按钮，←→ 和 ↑↓ 都换图（随机壁纸会取新的一张），确认或返回回到按钮。
- 背景设置页（h4、h5）：
  - 入口在电视设置的“电视”组（Z3 A）。
  - 四个来源、填充（选项）、遮罩（滑块行，←→ 调）、模糊（选项）。
  - 清除背景先确认，焦点在“取消”。
- 网格里正在用的图写“✓ 当前”（h8）。纯色和渐变一页里，当前那一个也有这个标记。
- 视频壁纸和直播不同时解码：电视直播间打开时，视频壁纸暂停（`TvWallpaperVideo.hold`），离开后继续。点播（A17.6）也会照这样做。
- 测试：`test/tv/tv_wallpaper_test.dart`，7 个用例：
  - 敏感来源不出现；随机接口取图片地址的规则、带 key 的请求；Wallhaven 只要全家能看的图；默认值；
  - 只模糊一次、清理旧文件；
  - 背景层；
  - 预览里的修改按返回不保存、设为背景一起保存、沉浸式。
  - 另外 `tv_test` 的目录用例加了“背景设置”一行。

## 要在电视上看的

- 背景设置的焦点和底色；纯色或渐变后，首页、浏览页、设置页后面都是它。
- 壁纸库和随机壁纸能不能出图（要联网，部分随机接口可能失效）。
- 模糊 16 时，在低端盒子上切换页面是否流畅。
- 视频壁纸进直播间后暂停、回来继续。
