# A17.17 电视代理禁用输入焦点

来源：[# 52](https://github.com/wzgrx/PureLive/issues/52)。

关闭代理时禁用编辑区排除遥控器焦点，保持开关和启用后的地址、端口编辑。

允许目录：apps/pure_live/lib/features/settings/settings_editors.dart；apps/pure_live/test/tv/tv_proxy_focus_test.dart；本任务文档。

5.4.15原候选C4、六个本地正式包、原生回执和私有草稿已完整保留，Apple原始运行40177564886继续保留，不作为本候选验收。新候选C5必须重新完整all/14、构建全部十包及各端原生核对后才能发布；仅操作授权v4dev和隔离桌面实例，不动正式数据。

复现：电视模式进入自定义网络代理，两个代理开关保持关闭；首次向下从应用层代理开关进入灰色地址框，焦点框消失。Flutter方向导航仍允许禁用TextField取焦，修正为仅在禁用编辑区ExcludeFocus，不改变代理地址、端口、启用状态、网络或正常编辑。
