# A13.4 开发记录

来源：issue #32；用户要求解决新 issues、发布更新、合并 PR 并关闭已解决报告。按 D-003 由维护者选择最小方案。

根因：MultiviewLayout 只有 single/dual/quad/focus；WallGeometry 的 quad 固定两列两行，不能将四路依次竖排。3.x 同样没有四路单列布局。

增加 vertical（1×4）布局，四路按已有顺序从上到下排列，每格保留 16:9；按宽高等比例缩放，居中，不裁切。默认仍为四宫格，不改变已有布局或设置键。布局按名字持久化；同容量切换、窗口缩放和全屏沿用各格 session、房间和声音选择。窄屏布局选项可以横向滑动，原四项密度阈值不变，不缩小文字去挤五项。

逐项界面：顶部布局选择增加 1×4；普通宽屏和竖屏显示器四格纵向排列；紧凑屏布局栏可滑动；沉浸/全屏使用同一墙体；空格、错误、离线、换台与声音来源沿用已有组件。Windows/Linux/macOS 共用实现；手机和平板同样可选择。

验证：geometry 与页面两项回归在旧代码上失败（坐标不在同列、缺少 vertical 入口）。新增 session/音频与保存恢复回归；覆盖 1080×1920、1280×800、393×852、740×360、窗口缩放及全屏。合成截图用于布局审查，原生运行结果另记。设计按 D-003 自行选择；旧 Claude 私有评审页流程不再可用，本任务保留代码截图与本地说明供审查。

本节为开工范围；最终结果见下方发布交付记录。
