# J05.2 设备发现异步网络错误隔离

## 根因与范围

缺少广播路由时，`RawDatagramSocket.send` 的本地发送失败会作为 Stream 错误异步发出，`_announce` 的同步 try/catch 不能拦截。发现监听器缺少 onError，导致可选的广播发现错误进入应用错误区。

修复仅为发现流增加错误处理，保留 HTTP 同步、地址/配对码/二维码、mDNS 与 stop 资源清理。默认仍绑定相同地址和端口；配对、传输协议、设置及权限不变。可注入的 socket 绑定接口仅用于确定性回归。

当前 Dart SDK 在报告本地 UDP 错误后会关闭底层 socket；回归也覆盖错误后关闭。保证的是其他可用同步路径，不承诺广播通道自动重建。

3.x 的地址配对和 mDNS 兼容协议不变。此项作为 G02.9 候选的独立依赖提交与审查，不代表局域网真机互发现已经验收。
