# D01.34 斗鱼贵宾数显示为在线数（接 D01.3）

- 类型：平台
- 来源：用户 2026-10-28
- 相关：D01.3、E01.2、决定 D-070

## 目标

斗鱼弹幕里的贵宾数不再以“贵宾”聊天行出现在弹幕列表，改为显示在直播间的热度、已开播那一栏，标签是“贵宾”（哔哩哔哩的同类数字显示“在线”）；数据仍从弹幕 ws 的 `oni` 包取。

## 做法

`DouyuDanmakuProtocol`仍通过online事件传递，但负载改为独立的`LiveVipCount`，不再使用`LiveAudienceUpdate(onlineViewers)`。控制器只在当前斗鱼直播间会话保留人数；广播结束、重新加载或换房后不沿用旧值。信息栏、详情、电视浮层统一显示“贵宾”，零值也显示；真人同名聊天保留。数据不写入LiveRoom.onlineViewers，不影响房间卡片、排序或持久化快照。`oun`仍不上报；非数字、负值和其他房间数据忽略。见纠正决定D-073。

## 和 5.4.19 的贵宾开关

5.4.19 曾加“显示斗鱼贵宾人数通知”开关（`danmakuShowVipCount`，默认关）。本任务让贵宾数固定显示在观众栏、不再进入弹幕列表，因此同步上游后移除了这个开关及其过滤、翻译和清单条目（见 record.md）。

## 验收

1. 斗鱼弹幕列表里不再出现“贵宾”聊天行。
2. 直播间观众栏（和详情页）出现“贵宾 + 人数”，每收到一次 `oni` 更新一次；哔哩哔哩等其他平台仍显示“在线”。
3. 别的房间的 `oni`、空数字或非数字不显示。
4. 哔哩哔哩等其他平台不变。
